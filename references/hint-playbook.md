# 막힘 도우미 — 답을 주지 않고 힌트만 (소상공인 버전)

**인터뷰가 무너지는 지점은 "잘 모르겠는데요"다.**
여기서 AI가 답을 대신 써버리면 그 답에 생각이 갇힌다. 그리고 소상공인 수업에서는 **AI가 쓴 문장을 그대로 간판에 거는 일**이 실제로 생긴다.

---

## 3단으로 간다

```
① 질문한다
    ↓  "잘 모르겠는데요"
② 먼저 물어본다  ← 건너뛰지 않는다
   "지금까지 말씀해주신 걸로 힌트를 드릴까요?"
    ↓  "네"
③ 힌트를 준다 — 답이 아니라 방향
    ↓  그래도 안 나오면
④ 보기를 준다 — 고르게 하고, 고른 뒤 본인 말로 바꾸게 한다
```

---

## 힌트의 원칙

| # | 원칙 | 왜 |
|---|---|---|
| **1** | **본인이 말한 재료에서만 뽑는다** | 일반론을 주면 옆 가게 답이 된다 |
| **2** | **완성 문장을 주지 않는다** | 방향만 |
| **3** | **두세 개.** 하나면 정답처럼 보인다 | 고를 여지 |
| **4** | **힌트로 나온 답도 본인 말로 다시 쓰게 한다** | 그래야 자기 것이 된다 |
| **5** | **사실은 힌트로 주지 않는다** | 년수 · 원산지 · 수상을 AI가 제안하면 그게 시트에 들어간다 |

---

## 블록별 힌트의 출처

| 막히는 곳 | 힌트를 어디서 뽑나 | 실제 문장 |
|---|---|---|
| **A-③ 안 오는 이유** | A-② 처음 온 사람의 질문 | *"처음 온 분이 '주차 돼요?'를 묻는다고 하셨죠. 그 답이 '안 돼요'인 분은 다시 올까요?"* |
| **Before** | A-② 질문 | *"'초보도 돼요?'라고 묻는 분은 지금 어떤 상태일까요?"* |
| **After** | A-① 단골의 말 | *"단골이 '여기 오면 ○○'라고 한다고 하셨죠. 그게 After 아닐까요?"* |
| **대안** | 안 하는 쪽 | *"안 오면 다른 데 가나요, 집에서 대충 하나요, 그냥 안 하나요?"* |
| **대체 불가 (우리 쪽)** | 반복 질문 · 반복 칭찬 | *"리뷰에 '○○'가 반복된다고 하셨죠. 다른 데선 그게 안 된다는 뜻일 수 있어요"* |
| **대체 불가 (사장님)** | 소개 ③ 년수 · 전직 | *"○년 하셨고 전에 ○○를 하셨다고요. 그중에 손님이 확인할 수 있는 건요?"* |
| **한 문장** | Before 끝줄 + After 끝줄 | *"Before 마지막 줄과 After 마지막 줄을 맞물리면 나와요"* |
| **가치** ★ | A-①, A-④ 실제 문장 | 아래 |
| **페르소나** | 지난달 손님 | *"지난달 오신 분 중에 계산하면서 제일 기분 좋았던 한 분은요?"* |
| **말투 (E-①)** | 대화 로그 | 사용자가 친 문장을 그대로 보여준다. 새로 묻지 않는다 |
| **왜 시작했나 (E-③)** | 소개 ① ③ | *"○년 전에 이걸 시작하신 계기가 있었을 것 같아요. 한 줄로요"* |

## 가치에서 막힐 때 — 제일 자주 막힌다

### 질문
```
그분이 우리한테 다녀가고 주변에 뭐라고 말할까요?
"거기 가보니까 ___" — 뒤를 채워주세요.
```

### "잘 모르겠어요"가 나오면 — 먼저 물어본다
```
지금까지 말씀해주신 것들로 힌트를 드릴까요?
답을 드리는 게 아니라, 어디를 보면 될지만요.
```

### "네" 하면
```
두 군데를 보면 나올 것 같아요.

① 아까 단골이 소개할 때 "○○○"라고 한다고 하셨죠.
   그 말을 처음 온 분이 한다면 뭐라고 할까요?

② 리뷰에 "○○○"가 있다고 하셨죠. 그 문장 그대로는 어때요?

둘 중에 뭐가 더 가까우세요?
```

> **②가 특히 잘 걸린다.** 리뷰는 이미 손님 말로 쓰여 있다. 지어내는 게 아니라 **꺼내는 것**이다.

### 그래도 안 나오면 — 보기를 준다
```
그럼 이 중에 가까운 게 있나 볼까요?

A. "거기 가보니까 생각보다 (부담·어려움)이 없더라"
B. "거기 가보니까 (구체적 상황)에도 되더라"
C. "거기 가보니까 왜 (그동안 안 됐는지)를 알겠더라"

고르신 다음에, 그분이 실제로 쓸 것 같은 말로 살짝 바꿔주세요.
```

## 한 문장에서 막힐 때

**초안 세 개를 뒷칸 추상도만 다르게 낸다.**

```
초안 세 개예요. 고르시거나 섞으셔도 됩니다.

1. (구체) "우리는 반찬을 파는 게 아니라, 저녁 한 끼 걱정이 없는 퇴근길을 판다"
2. (중간) "우리는 반찬을 파는 게 아니라, 집밥을 포기하지 않는 방법을 판다"
3. (넓게) "우리는 반찬을 파는 게 아니라, 잘 먹고 있다는 안심을 판다"

어느 쪽이 사장님 생각에 가까워요? 고르고 나서 사장님 말로 고쳐주세요.
```

**사용자가 "다 좋은데요"라고 하면** — *"손님(D) 한 분을 떠올리면 그분한테 제일 맞는 건요?"*

## 막힘을 어떻게 감지하나

| 신호 | 대응 |
|---|---|
| *"잘 모르겠어요"* · *"음…"* | 힌트 제안 |
| **추상적인 답** — *"좋은 곳이에요"* | 되묻기 먼저 |
| **길게 쓰는데 겉도는 경우** | *"한 문장만 골라주실래요?"* |
| **같은 말 반복** | 다른 각도로 질문을 바꾼다 |
| **답 대신 질문** — *"보통은 뭐라고 해요?"* | *"보통 답은 옆 가게 답이 돼요. 사장님 걸로 갈게요"* + 힌트 제안 |
| **AI가 대신 써달라고 함** | *"초안은 드릴게요. 대신 고르고 고치시는 건 사장님이 해주셔야 해요"* |

---

## 소상공인 수업에서 특히 조심할 것

- **타이핑이 느린 분**이 있다. *"짧게, 단어로만 주셔도 돼요"* 를 초반에 말해둔다
- **"보통 이렇게 하잖아요"** 식 답은 업계 상식이다. 사장님 것으로 되돌린다
- **AI 초안을 바로 확정하려는 분**이 있다. 반드시 *"사장님 말로 한 번 고쳐주세요"* 를 거친다
- **사실을 부풀리는 답**(*"거의 30년"*)은 힌트가 아니라 되묻기로 간다 — *"정확히요"*

---

## 하지 않는 것

- **묻지 않고 힌트를 주지 않는다**
- **완성 문장을 힌트로 주지 않는다** (한 문장 초안은 예외. 그것도 고치게 한다)
- **힌트를 네 개 이상 주지 않는다**
- **보기를 고른 뒤 그대로 확정하지 않는다**
- **사실(숫자 · 원산지 · 수상)을 힌트로 제안하지 않는다**
