# 우리 가게 GTM 코어 (gage-gtm-core)

**아이템은 이미 있어요. 문제는 그 아이템이 누구의 무엇을 바꾸는지 아무도 적어두지 않았다는 거예요.**

[`sponge-gtm-core`](https://github.com/selfishclub/sponge-gtm-core)를 **이미 팔고 있는 가게 사장님**용으로 뒤집은 스킬입니다.
클로드가 열아홉 개쯤 질문을 하나씩 던지고, 답하다 보면 **클로드 프로젝트에 바로 넣을 파일 여섯 개**가 나옵니다.

> 2026 소상공인 디지털 마케팅 실무교육 · 1회차 「SNS 세팅 + 우리 가게에 맞는 SNS 마케팅 전략 수립」에서 씁니다.

| `05_콘텐츠_방향_1개월.md` | 프로젝트 지식 |

2회차(카드뉴스) · 3회차(이미지) · 4회차(릴스)는 **이 파일들을 읽고 시작**합니다. 첫 질문을 다시 하지 않아요.

---

## 3층 구조

| 3층 | 블록 | 콘텐츠 기둥 |
|---|---|---|
| **내가 파는 것** | A 재료 · B 변화 | 상품 · 공간 → 3회차 이미지 |
| **사는 사람** | D 페르소나 · C 가치 | 손님의 변화 → 2회차 카드뉴스 |
| **나라는 사람** | E 사장님 | 사장님 → 4회차 릴스 |
| *(받침)* | F 가게 사실 시트 | 모든 회차의 검수 기준 |

**아이템은 바꾸지 않습니다.** 무엇을 앞세울지만 바꿉니다.

## 원본과 뭐가 다른가요

| | 원본 `sponge-gtm-core` | 이 스킬 |
|---|---|---|
| 대상 | 아이템 없음 · 생각만 · 팔고 있음 | **팔고 있음**만 |
| 방향 | 재료에서 변화, 아이템은 나중 | **아이템에서 변화를 역산** |
| 가장 센 재료 | 환불 사유 | 단골이 소개할 때 하는 말 · 한 번 오고 안 오는 이유 |
| "왜 하필 나" | 막음 (경력으로 새서) | **가게 기준 / 사장님 기준** 두 칸으로 분리 |
| 사장님 · 사실 시트 | 없음 | E · F 블록 추가 |
| 산출 | 문서 한 장 | 지침 1 + 지식 파일 5 |

## 설치

### 클로드 앱 (데스크탑 · 웹)

1. [`gage-gtm-core.skill`](gage-gtm-core.skill) 파일을 내려받아요
2. 클로드에서 **Customize → Skills** 로 갑니다
3. **+ → Create skill → Upload a skill** 을 고르고 내려받은 파일을 올려요

### 클로드 코드

```bash
git clone https://github.com/selfishclub/gage-gtm-core.git ~/.claude/skills/gage-gtm-core
```
