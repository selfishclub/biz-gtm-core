# 인터뷰 가이드 — 소상공인 버전 질문 전문

**한 번에 한 질문.** 전체 **19~20개**, 약 90분.
**호칭** — 아래 질문의 "우리"는 사용자가 소개에서 자기 것을 부른 말(가게 · 스토어 · 공방 · 샵 · 학원)로 바꿔 말한다. 안 나왔으면 "우리"로만.

| 단계 | 블록 | 질문 수 |
|---|---|---|
| 0 | 소개 + 상태 확인 | 1~2 |
| 1 | A · 재료 (또는 예정 재료 / 씨앗 찾기) | 4 |
| 2 | B · 변화 | 6 (대체 불가가 2칸) |
| 3 | D · 페르소나 | 2 |
| 4 | C · 가치 | 1 |
| 5 | E · 사장님 | 3 |
| 6 | F · 사실 시트 (표 1회) | 1 |
| 7 | 채널 · 기둥 · 1주차 3개 | 3 |
| **합계** | | **20~21** |

시간이 없으면 **E-③ · A-④** 를 먼저 뺀다. B와 D와 C, 1주차 3개는 빼지 않는다.

## 0. 소개 — 그리고 세 상태

```
먼저 무엇을 하시는지 짧게 소개해주세요. 네 가지만요.

① 무엇을 파세요? (대표 상품·메뉴·서비스 한두 개) — 예정이면 팔려는 것
② 어디서요? (동네·온라인·배달 등)
③ 몇 년 하셨어요? — 예정이면 "예정"
④ 지금 하고 있는 SNS나 채널이 있으세요?
   (인스타·네이버 플레이스·배민·스마트스토어·카카오채널·블로그·당근 등)
```

**소개에서 세 상태 중 하나를 읽는다.** 읽히면 되묻지 않는다. 안 읽히면 한 번 묻는다.

```
지금 어느 쪽에 가까우세요?
1) 지금 팔고 있다
2) 팔 것은 정했는데 아직 손님은 없다 (오픈 전 · 새 아이템 준비)
3) 뭘 팔지 아직 정하지 않았다
```

| 상태 | 어떻게 가나 |
|---|---|
| **1 팔고 있다** | 아래 STEP 1 「A · 재료」 그대로 |
| **2 팔 것은 정했다 · 손님 없음** | STEP 1을 **「A′ · 예정 재료」** 로 바꾼다. 나머지는 같다 |
| **3 미정** | **「씨앗 찾기」 3문항** → 후보 고르기 → 상태 2로 합류. 강사에게 알린다 |

**세 상태 모두 이 스킬 안에서 끝낸다.** 다른 스킬로 보내지 않는다. 수업 중에 보내면 그 사람은 혼자가 된다.

| 이런 답이 오면 | 이렇게 |
|---|---|
| 상품이 다섯 개 이상 나열 | *"그중 매출이나 손님 반응이 제일 큰 하나만 오늘의 기준으로 잡을게요. 어떤 거예요?"* |
| 온라인만 판다 (스마트스토어 · 자사몰) | 아래 A 문항의 **「온라인이면」** 문구로 바꿔 묻는다 |
| ④에 채널이 4개 이상 | *"많이 하고 계시네요. 오늘은 그중 '안 할 것'도 정할 거예요"* 예고 |
| ④에 SNS가 있음 | *"나중에 반응 제일 좋았던 게시물 하나 여쭤볼게요"* 예고 |
| 상호가 있음 · 웹 검색 가능 | **[조사] 사전 확인** — *"잠깐 상호로 검색해볼게요. 이미 올라온 리뷰가 있으면 재료로 쓸 수 있어요."* 5분, 다섯 줄, 출처. → `research.md` ① |

## 1. A · 재료 — 팔고 있는 분

```
① 단골이 다른 사람한테 우리를 소개할 때 뭐라고 하나요? 들은 말 그대로가 제일 좋아요.
   (온라인이면) 두 번 이상 산 분이 후기나 문의에 뭐라고 쓰나요?
```
```
② 처음 온 손님이 꼭 묻는 게 있어요?
   (예: "여기 뭐가 맛있어요?", "주차 돼요?", "혼자 와도 돼요?", "초보도 돼요?")
   (온라인이면) 스토어 Q&A나 톡톡으로 제일 많이 오는 질문이 뭐예요?
```
```
③ 한 번 오고 다시 안 오는 분들은 왜 안 올까요? 짐작이라도 괜찮아요.
   (온라인이면) 장바구니에 담고 안 사는 분, 한 번 사고 안 사는 분, 반품하는 분은 왜일까요?
```
```
④ 리뷰(네이버·배민·구글·스마트스토어)에 반복해서 나오는 칭찬이나 불만이 있어요?
   기억나는 문장이 있으면 그대로요.
```

| 이런 답이 오면 | 이렇게 되묻는다 |
|---|---|
| ① *"맛있다고 해요"* | *"맛있다 다음에 뭐라고 하나요? '~라서 맛있다' 의 뒷부분요"* |
| ② *"그냥 뭐가 맛있냐고요"* | *"그 질문을 하는 분은 어떤 상태일까요? 뭘 모르고 뭘 걱정해서 물을까요?"* |
| ③ *"모르겠어요"* | *"위치, 가격, 기대와 달랐던 것 중에 하나 골라보면요?"* 한 번만. 그래도 없으면 ☐ |
| ④ *"리뷰가 별로 없어요"* | *"그럼 직접 들은 말로요. 계산할 때 손님이 한 말 같은 거"* |

## 1′. A′ · 예정 재료 — 팔 것은 정했는데 손님이 없는 분

**손님의 말이 없으니 사장님 본인과 주변에서 캔다.** 네 문항, 같은 자리에 들어간다.

```
① 왜 이걸 팔기로 하셨어요? 계기가 된 일이 있었나요?
```
```
② 사장님이 이걸 사는 손님이었을 때, 뭐가 불편했어요? 어디서 사셨어요?
```
```
③ 이걸 이미 써본 사람(가족 · 친구 · 시장 테스트)이 있으면, 그 사람이 뭐라고 했어요?
   없으면 "없어요"도 괜찮아요.
```
```
④ 참고하는 가게나 계정이 있어요? 거기 손님들은 뭘 좋아하는 것 같아요?
```

| 문항 | 어느 칸의 재료가 되나 |
|---|---|
| ① | E-③ 왜 시작했나 · B-④ 사장님 기준 |
| ② | **Before** · 대안 |
| ③ | C 가치의 첫 후보 (실제 들은 말) |
| ④ | D 페르소나 · 채널 |

**B에서 바뀌는 것 하나** — B-① 「가장 만족한 손님」을 이렇게 묻는다.
```
이걸 받으면 제일 좋아할 사람 한 명을 떠올려보세요. 아는 사람이어도 돼요.
그 사람은 뭘 얻게 되나요?
```
나머지 B-② ~ ⑤, D, C는 그대로. **C 가치는 「짐작」으로 표시**하고 `01`의 「비어 있는 것」에 *"첫 손님 3명에게 실제로 듣기"* 를 넣는다.

## 1″. 씨앗 찾기 — 뭘 팔지 미정인 분

원본 `sponge-gtm-core` 유형 1의 축약판. **3문항 → 후보 3개 → 고르기 → 상태 2로 합류.**

```
① 지금 하고 계신 일, 또는 잘 아는 분야가 뭐예요?
```
```
② 사람들이 사장님한테 자꾸 물어보는 게 있어요?
```
```
③ 돈 받고 한 적은 없는데, 공짜로 해준 적 있는 건 뭔가요?
```

```
말씀하신 것들을 보니 이런 게 재료가 될 수 있겠어요.

1. ○○○
2. ○○○
3. ○○○

이 중에 "이건 좀 해볼 만한데" 싶은 게 있으세요? 없으면 다른 각도로 다시 뽑아볼게요.
```

- 후보는 **반드시 본인이 말한 재료에서**. 일반적인 창업 아이템을 제시하지 않는다
- *"없다"* 면 다른 각도로 **최대 3회**. 그 뒤엔 ①~③으로 돌아가 더 캔다
- 골랐으면 *"오늘은 이걸 기준으로 갈게요. 바뀌어도 돼요"* 하고 **A′ 예정 재료**로 간다
- **강사에게 알린다.** 이 분기는 시간이 더 걸린다

## 2. B · 변화

```
① 지금까지 온 손님 중에 "이분은 진짜 우리한테 잘 왔다" 싶었던 한 분을 떠올려보세요.
   그분은 우리한테서 뭘 얻어 갔나요?
   (손님 없음) 이걸 받으면 제일 좋아할 사람 한 명을 떠올려보세요. 그 사람은 뭘 얻게 되나요?
```
```
② 그분이 우리한테 오기 전엔 어떤 상태였을까요? (Before)
   다녀간 뒤엔 뭐가 달라졌나요? (After)
```
```
③ 우리 걸 안 사면, 그분은 대신 어떻게 하나요?
```
```
④-1 왜 하필 우리여야 하나요?
     먼저 「우리 쪽 기준」으로요. 재료 · 만드는 방식 · 시간 · 위치 · 가격 · 공간 · 배송 같은 것.
```
```
④-2 이번엔 「사장님 기준」으로요.
     사장님이라서 되는 게 있다면요?
     자격 · 년수 · 직접 하는 것 · 전에 했던 일처럼 확인 가능한 것으로요.
```
```
⑤ 이걸 한 문장으로 만들어볼게요.

   "우리는 ___를 파는 게 아니라, ___를 판다"

   제가 초안 세 개를 드릴 테니 고르시거나 고쳐주세요.
```

| 이런 답이 오면 | 이렇게 되묻는다 |
|---|---|
| ① 메뉴 이름만 | *"그 메뉴를 먹고 그분한테 뭐가 남았을까요?"* |
| ② 기능 · 공정 설명 | *"그건 우리가 하는 일이고, 그래서 그분 하루에서 뭐가 달라졌나요?"* |
| ③ 경쟁 가게 이름 | *"거기 가는 것 말고, 아예 안 가는 경우는 없어요? 집에서 해결하거나"* |
| ④-1 *"퀄리티가 달라요"* | *"손님이 그걸 어떻게 알아채나요? 보이는 것으로요"* |
| ④-2 *"정성 · 진심 · 열정"* | *"손님이 그걸 어떻게 알아채나요? 자격이나 년수나 직접 하는 일 같은 걸로요"* |
| ④-2 답이 없음 | ☐로 두고 넘어간다. 사장님 칸은 비어도 된다 |
| ⑤ 세 칸으로 벌어짐 | *"둘 중 하나만 남기면요? 나머지는 조건으로 한 줄 덧붙일게요"* |

**한 문장 초안을 낼 때** — Before 마지막 줄과 After 마지막 줄을 맞물린다. 세 초안은 **뒷칸의 추상도**를 다르게 한다(구체 · 중간 · 넓게). 사용자가 고른 뒤 **본인 말로 고치게** 한다.

## 3. D · 페르소나

```
① 이 변화를 가장 바라는 손님을 한 분으로 좁히면 누구예요?
   지난달 오신 분 중에 제일 잘 맞았던 한 분을 떠올려도 됩니다.
   (손님 없음) 아까 떠올린 그 사람이어도 돼요. 그분을 조금 더 그려볼게요.
```
```
② 그분은 우리한테 오기 직전에 뭘 하고 있었을까요? 뭐가 막혀서 왔을까요?
```

| 이런 답이 오면 | 이렇게 되묻는다 |
|---|---|
| *"다요"* · *"동네 주민"* | *"그중에 우리가 없으면 제일 아쉬워할 한 분은요?"* |
| *"30대 여성"* | *"그분이 오기 직전에 뭘 하다가 왔을까요?"* (②로 바로) |
| 두 명이 나옴 | *"오늘은 한 분만요. 나머지 한 분은 적어두고 나중에 가치를 따로 씁니다"* |

## 4. C · 가치

```
그분이 우리한테 다녀가고 주변에 뭐라고 말할까요?
"거기 가보니까 ___" — 뒤를 채워주세요.
실제로 들은 말이 있으면 그 말 그대로가 제일 좋아요. 네이버 리뷰 문장도 됩니다.
```

| 이런 답이 오면 | 왜 | 이렇게 |
|---|---|---|
| *"재료가 신선해요"* | 사장님 말 | *"손님이 그걸 느꼈을 때 실제로 뭐라고 할까요?"* |
| B의 뒷칸을 그대로 | 변화 복붙 | *"그건 우리가 정한 변화고, 손님은 그걸 자기 말로 뭐라고 할까요?"* |
| *"맛있어요"* | 옆 가게도 가능 | *"옆 가게 손님도 똑같이 말할 수 있는 말이에요. 우리한테서만 나올 말은요?"* |
| *"믿고 먹는 집, 지금 방문하세요"* | 카피 | *"그건 광고 문구예요. 손님이 친구한테 카톡으로 보낼 말로요"* |

막히면 → `hint-playbook.md`의 「가치에서 막힐 때」. **첫 힌트 출처는 네이버 리뷰 문장.**

## 5. E · 사장님

```
① 지금까지 저한테 설명하시면서 이렇게 쓰셨어요.

     "(대화에서 사용자가 실제로 친 문장 1)"
     "(문장 2)"
     "(문장 3)"

   이게 사장님 말투예요. 손님한테 실제로 자주 하는 말도 한두 개 더 있으면 알려주세요.
```
```
② 절대 안 쓰는 말이나 싫어하는 표현이 있어요?
   (예: "핫플", "인생 맛집", 이모지 남발, 반말, "~하는 중")
   그리고 SNS에 안 올리고 싶은 것도요. (얼굴 · 주방 · 가격 · 가족 · 매출 등)
```
```
③ 이 장사를 왜 시작하셨어요?
   그리고 남들은 안 하는데 사장님은 꼭 지키는 게 하나 있다면요?
   각각 한 문장씩만요.
```

**①에서 채집할 문장 고르는 기준** — 짧고, 구어체고, 사장님 특유의 어미나 단어가 있는 것. 정중한 설명문은 고르지 않는다.
**③이 길어지면** — *"그중에 한 줄만 고르면요?"* B로 되돌려 넣지 않는다. **예정 재료 ①에서 이미 나왔으면 확인만 한다.**

## 6. F · 사실 시트

```
이제 사실만 적는 표예요. 아는 것만, 확실한 것만 채워주세요. 모르면 비워두세요.
예정이면 정해진 것만요.

| 항목 | 내용 |
|---|---|
| 정식 상호 · 검색되는 이름 | |
| 주소 · 찾아오는 법 · 주차 (온라인이면 배송 · 배송비 · 소요일) | |
| 영업시간 · 휴무 · 라스트오더 (온라인이면 주문 마감 · 발송 요일) | |
| 대표 상품과 가격 (3개까지) | |
| 원산지 · 인증 · 자격 · 수상 (증명 가능한 것만) | |
| 시작한 연도 · 년수 | |
| 예약 · 주문 · 문의 방법 | |

```

받은 뒤 **[조사] 규정 조회**를 한다 — *"이 업종에서 쓰면 안 되는 표현을 잠깐 찾아볼게요."* 결과를 `[조사]`와 출처로 보여주고 사장님 확인을 받은 뒤 「말하면 안 되는 것」에 넣는다. → `research.md` ②
그다음 `facts-sheet-guide.md`의 「말하면 안 되는 것」 공통 항목을 한 번 짚는다.

# 막힘 도우미 — 답을 주지 않고 힌트만 (소상공인 버전)

**인터뷰가 무너지는 지점은 "잘 모르겠는데요"다.**
여기서 AI가 답을 대신 써버리면 그 답에 생각이 갇힌다. 그리고 소상공인 수업에서는 **AI가 쓴 문장을 그대로 간판에 거는 일**이 실제로 생긴다.

---

## 3단으로 간다

```
① 질문한다
    ↓  "잘 모르겠는데요"
② 먼저 물어본다  ← 건너뛰지 않는다
   "지금까지 말씀해주신 걸로 힌트를 드릴까요?"
    ↓  "네"
③ 힌트를 준다 — 답이 아니라 방향
    ↓  그래도 안 나오면
④ 보기를 준다 — 고르게 하고, 고른 뒤 본인 말로 바꾸게 한다
```

---

## 힌트의 원칙

| # | 원칙 | 왜 |
|---|---|---|
| **1** | **본인이 말한 재료에서만 뽑는다** | 일반론을 주면 옆 가게 답이 된다 |
| **2** | **완성 문장을 주지 않는다** | 방향만 |
| **3** | **두세 개.** 하나면 정답처럼 보인다 | 고를 여지 |
| **4** | **힌트로 나온 답도 본인 말로 다시 쓰게 한다** | 그래야 자기 것이 된다 |
| **5** | **사실은 힌트로 주지 않는다** | 년수 · 원산지 · 수상을 AI가 제안하면 그게 시트에 들어간다 |

---

## 블록별 힌트의 출처

| 막히는 곳 | 힌트를 어디서 뽑나 | 실제 문장 |
|---|---|---|
| **A-③ 안 오는 이유** | A-② 처음 온 사람의 질문 | *"처음 온 분이 '주차 돼요?'를 묻는다고 하셨죠. 그 답이 '안 돼요'인 분은 다시 올까요?"* |
| **Before** | A-② 질문 | *"'초보도 돼요?'라고 묻는 분은 지금 어떤 상태일까요?"* |
| **After** | A-① 단골의 말 | *"단골이 '여기 오면 ○○'라고 한다고 하셨죠. 그게 After 아닐까요?"* |
| **대안** | 안 하는 쪽 | *"안 오면 다른 데 가나요, 집에서 대충 하나요, 그냥 안 하나요?"* |
| **대체 불가 (우리 쪽)** | 반복 질문 · 반복 칭찬 | *"리뷰에 '○○'가 반복된다고 하셨죠. 다른 데선 그게 안 된다는 뜻일 수 있어요"* |
| **대체 불가 (사장님)** | 소개 ③ 년수 · 전직 | *"○년 하셨고 전에 ○○를 하셨다고요. 그중에 손님이 확인할 수 있는 건요?"* |
| **한 문장** | Before 끝줄 + After 끝줄 | *"Before 마지막 줄과 After 마지막 줄을 맞물리면 나와요"* |
| **가치** ★ | A-①, A-④ 실제 문장 | 아래 |
| **페르소나** | 지난달 손님 | *"지난달 오신 분 중에 계산하면서 제일 기분 좋았던 한 분은요?"* |
| **말투 (E-①)** | 대화 로그 | 사용자가 친 문장을 그대로 보여준다. 새로 묻지 않는다 |
| **왜 시작했나 (E-③)** | 소개 ① ③ | *"○년 전에 이걸 시작하신 계기가 있었을 것 같아요. 한 줄로요"* |

---

## 가치에서 막힐 때 — 제일 자주 막힌다

### 질문
```
그분이 우리한테 다녀가고 주변에 뭐라고 말할까요?
"거기 가보니까 ___" — 뒤를 채워주세요.
```

### "잘 모르겠어요"가 나오면 — 먼저 물어본다
```
지금까지 말씀해주신 것들로 힌트를 드릴까요?
답을 드리는 게 아니라, 어디를 보면 될지만요.
```

### "네" 하면
```
두 군데를 보면 나올 것 같아요.

① 아까 단골이 소개할 때 "○○○"라고 한다고 하셨죠.
   그 말을 처음 온 분이 한다면 뭐라고 할까요?

② 리뷰에 "○○○"가 있다고 하셨죠. 그 문장 그대로는 어때요?

둘 중에 뭐가 더 가까우세요?
```

> **②가 특히 잘 걸린다.** 리뷰는 이미 손님 말로 쓰여 있다. 지어내는 게 아니라 **꺼내는 것**이다.

### 그래도 안 나오면 — 보기를 준다
```
그럼 이 중에 가까운 게 있나 볼까요?

A. "거기 가보니까 생각보다 (부담·어려움)이 없더라"
B. "거기 가보니까 (구체적 상황)에도 되더라"
C. "거기 가보니까 왜 (그동안 안 됐는지)를 알겠더라"

고르신 다음에, 그분이 실제로 쓸 것 같은 말로 살짝 바꿔주세요.
```

---

## 한 문장에서 막힐 때

**초안 세 개를 뒷칸 추상도만 다르게 낸다.**

```
초안 세 개예요. 고르시거나 섞으셔도 됩니다.

1. (구체) "우리는 반찬을 파는 게 아니라, 저녁 한 끼 걱정이 없는 퇴근길을 판다"
2. (중간) "우리는 반찬을 파는 게 아니라, 집밥을 포기하지 않는 방법을 판다"
3. (넓게) "우리는 반찬을 파는 게 아니라, 잘 먹고 있다는 안심을 판다"

어느 쪽이 사장님 생각에 가까워요? 고르고 나서 사장님 말로 고쳐주세요.
```

**사용자가 "다 좋은데요"라고 하면** — *"손님(D) 한 분을 떠올리면 그분한테 제일 맞는 건요?"*

---

## 막힘을 어떻게 감지하나

| 신호 | 대응 |
|---|---|
| *"잘 모르겠어요"* · *"음…"* | 힌트 제안 |
| **추상적인 답** — *"좋은 곳이에요"* | 되묻기 먼저 |
| **길게 쓰는데 겉도는 경우** | *"한 문장만 골라주실래요?"* |
| **같은 말 반복** | 다른 각도로 질문을 바꾼다 |
| **답 대신 질문** — *"보통은 뭐라고 해요?"* | *"보통 답은 옆 가게 답이 돼요. 사장님 걸로 갈게요"* + 힌트 제안 |
| **AI가 대신 써달라고 함** | *"초안은 드릴게요. 대신 고르고 고치시는 건 사장님이 해주셔야 해요"* |

---

## 소상공인 수업에서 특히 조심할 것

- **타이핑이 느린 분**이 있다. *"짧게, 단어로만 주셔도 돼요"* 를 초반에 말해둔다
- **"보통 이렇게 하잖아요"** 식 답은 업계 상식이다. 사장님 것으로 되돌린다
- **AI 초안을 바로 확정하려는 분**이 있다. 반드시 *"사장님 말로 한 번 고쳐주세요"* 를 거친다
- **사실을 부풀리는 답**(*"거의 30년"*)은 힌트가 아니라 되묻기로 간다 — *"정확히요"*

---

## 하지 않는 것

- **묻지 않고 힌트를 주지 않는다**
- **완성 문장을 힌트로 주지 않는다** (한 문장 초안은 예외. 그것도 고치게 한다)
- **힌트를 네 개 이상 주지 않는다**
- **보기를 고른 뒤 그대로 확정하지 않는다**
- **사실(숫자 · 원산지 · 수상)을 힌트로 제안하지 않는다**

# 웹 조회 — 세 지점 · 규칙 · 리서치 숙제 프롬프트

**리서치는 보고서가 아니라 조회다.** 사장님이 답할 수 없는 것만, 세 지점에서, 각 5분, 다섯 줄 이내. 사장님 말을 대체하지 않고 받친다.

---

## 세 지점

| 지점 | 언제 | 무엇을 | 어디로 들어가나 |
|---|---|---|---|
| **① 사전 확인** | STEP 0 직후. 상호가 있을 때 | 상호 + 지역 검색. 플레이스 · 리뷰 · 인스타가 있나. 있으면 리뷰 문장 2~3개 | A 재료 힌트 (A-① ④). 없으면 「온라인에 아직 없다」가 상태 판별 근거 |
| **② 규정 조회** ★ | STEP 6 사실 시트 직후. **항상** | 이 업종에서 쓰면 안 되는 표현. 표시·광고 규정 | 03 「말하면 안 되는 것」에 근거 링크와 함께 |
| **③ 검색어 · 시즌** | STEP 7. **항상** | 손님(D)이 칠 검색어 5개(지역 + 업종 + 상황) · 앞으로 석 달 지역 이벤트 · 시즌 3개 | 04 대표 키워드 · 인스타 이름 칸 · 05 4주 테마 · 카카오채널 메시지 시점 |

**"필요한 경우에만"의 기준** — ②와 ③은 거의 항상 필요하다. ①은 상호가 있을 때만. 셋 다 웹 검색이 안 되면 건너뛰고 *"조회를 못 했으니 강사님 표를 보세요"* 라고 말한다.

---

## 규칙

1. **표기를 나눈다.** 사장님 말은 그대로, 조회한 것은 앞에 **[조사]**, 짐작은 **[추정]**. 섞지 않는다
2. **사장님 말이 이긴다.** 조회 결과가 사장님 말과 다르면 그걸 보여주고 묻는다. 고치는 건 사장님이다
3. **사실 시트에는 확인 뒤에만.** [조사]로 찾은 영업시간 · 주소도 사장님이 "맞아요" 한 뒤에 들어간다
4. **출처 링크를 붙인다.** 특히 ② 규정은 반드시
5. **다섯 줄 이내.** 길어지면 사장님이 읽다가 멈춘다
6. **만들지 않는 것** — 경쟁사 분석 · 시장 규모 · 트렌드 보고서 · SNS 채널 비교 리포트 · 조회 결과로 만든 페르소나나 가치

---

## ② 규정 조회 — 업종별로 무엇을 찾나

```
[조사 문구]
"{업종} 표시광고 금지 표현 {연도}" · "{업종} 광고 규정 식약처" · "{핵심 표현} 표기 기준"
```

| 업종 | 찾을 것 | 이 업체 예 |
|---|---|---|
| 화장품 · 천연제품 · 공방(비누 · 화장품) | 화장품법 표시·광고 기준. 「천연」「유기농」 인증 기준. "무첨가" "화학성분 없음" 오인 여부. 효능(미백 · 주름 · 아토피) | "화학성분 없이 천연원료로"는 그대로 못 쓸 가능성이 높다. 천연원료도 화학물질이고, 「천연화장품」은 인증 기준이 있다 |
| 식품 · 반찬 · 카페 · 건강식품 | 식품 표시광고법. 효능 · 질병 예방 · "건강한" · 원산지 표시 | |
| 미용 · 피부 · 헤어 · 네일 | 의료 행위 오인 표현. "재생" "치료" "탄력 회복". 전후 사진 규정 | |
| 학원 · 교육 · 레슨 | 합격률 · 수강생 수 근거. "누구나 ○개월" 보장 | |
| 운동 · 필라테스 | 감량 · 체형 교정 효과 단정 | |
| 공통 | 최초 · 최고 · 유일 · 1등 · 비교 · 근거 없는 숫자 · 없는 후기 | |

**결과를 이렇게 보여준다.**
```
[조사] 이 업종에서 이렇게 쓰면 문제가 될 수 있어요.
① "화학성분 없음" — 천연원료도 화학물질이라 오인 표현으로 볼 수 있어요 (출처: …)
② "천연화장품" — 식약처 인증 기준(천연 함량 등)이 있어요. 인증 없으면 「천연원료로 만드는」까지만 (출처: …)
③ "피부에 좋은" "아토피에" — 효능 표현이에요 (출처: …)

대신 쓸 수 있는 것: 원료 이름을 그대로 · 만드는 과정 · 손님이 한 말.
이 중에 "우리는 인증이 있어요" 하는 게 있으면 알려주세요. 시트에 넣고 쓸 수 있게 합니다.
```

> **법률 자문이 아니다.** 주의 안내이고 최종 판단은 사장님이 한다. 다만 "증명 못 하는 말은 쓰지 않는다"만 지키면 대부분 걸리지 않는다.

---

## ③ 검색어 · 시즌 조회

```
[조사 문구]
검색어: "{지역} {업종}" 연관 검색어 · "{지역} {상황}" (예: 부산 실내 데이트 · 서면 원데이클래스 · 아이와 가볼 만한 곳)
시즌: "{지역} {다음 3개월} 축제 행사" · 명절 · 기념일(발렌타인 · 어버이날 · 크리스마스)
```

**결과를 이렇게 보여준다.**
```
[조사] 손님이 실제로 칠 것 같은 검색어 다섯 개예요.
1. 서면 원데이클래스  2. 부산 실내 데이트  3. 부산 커플 체험  4. 천연비누 만들기 부산  5. 서면 데이트 코스
→ 인스타 이름 칸과 플레이스 대표 키워드에 넣을게요.

[조사] 앞으로 석 달의 계기예요.
· 9월 추석 (답례 · 선물)  · 10월 부산불꽃축제  · 11월 수능 끝 · 12월 크리스마스
→ 05의 4주 테마와 카카오채널 메시지 시점에 넣을게요.
```

**검색어는 D가 정해진 뒤에 조회한다.** 손님이 없으면 검색어도 없다.

## 리서치 숙제 프롬프트 — 인터뷰 뒤, 마케팅 프로젝트 안에서

사장님이 **더 넓은 리서치**를 원하면 이 프롬프트를 준다. 1회차 인터뷰 안에서 돌리지 않는다. 프로젝트에 01~05가 들어간 뒤에 돌려야 우리 맥락 위에서 답한다.

```
[상황] 프로젝트 파일 01~05가 우리 비즈니스다. 03 사실 시트에 없는 것은 사실로 쓰지 마.
[할 일] SNS 마케팅 방향을 정하기 전에 필요한 리서치만 해줘. 웹 기반 최신 정보로.
  - 어떤 항목을 조사할지는 우리 업종 · 지역 · 손님(01의 D)을 보고 네가 정하고, 항목마다 왜 조사하는지 한 줄 써줘
  - 조사 결과마다 신뢰도 검증(출처 · 날짜 · 교차 확인)을 붙여줘
  - 확인 안 된 것은 [추정], 조사한 것은 [조사]로 구분해줘
  - 지역 이벤트 · 시즌별 홍보 계기 · 무료 채널 활용 가능성 · 우리 업종의 표시광고 주의점을 포함해줘
[의도] 결과를 내가 읽고 판단한 뒤 다음 단계(방향 → 콘텐츠)로 간다.
[걱정] 페르소나 · 가치 · 콘텐츠 문구 · 콘텐츠 아이디어는 만들지 마. 리서치와 분석까지만.
  01의 손님과 C를 조사 결과로 바꾸지 마. 다르게 보이면 "다르게 보인다"고만 적어.
```

이 프롬프트는 상황 · 할 일 · 의도 · 걱정 네 줄(STIC)로 짜여 있다. 사장님이 다른 리서치를 시킬 때도 이 틀을 쓰면 된다.

# 사실 시트 — 말해도 되는 것과 말하면 안 되는 것

**이 파일이 2~4회차 검수 기준의 원본이다.**
카드뉴스 · 이미지 · 릴스를 만들 때 AI는 `03_사실시트.md`에 있는 것만 사실로 쓴다. 없는 건 **[확인 필요]** 로 표시하고 지어내지 않는다.

---

## 왜 1회차에 하나

| 사실 시트가 없으면 | 사실 시트가 있으면 |
|---|---|
| AI가 *"30년 전통"*, *"국내산 100%"* 를 만들어 넣는다 | 시트에 없는 숫자는 [확인 필요]로 멈춘다 |
| 2회차마다 사장님이 검수를 처음부터 한다 | 시트와 대조만 하면 끝난다 |
| 과장광고 지적이 나와도 뭐가 문제인지 모른다 | 어느 줄이 시트 밖인지 짚을 수 있다 |

---

## 시트 항목

| 항목 | 받을 때 확인할 것 |
|---|---|
| 정식 상호 · 검색되는 이름 | 네이버에 치면 나오는 이름과 같은가 |
| 주소 · 찾아오는 법 · 주차 | 주차는 **"돼요/안 돼요/근처 유료"** 셋 중 하나로 명확히 |
| 영업시간 · 휴무 · 라스트오더 | 요일별로 다르면 다 적는다 |
| 대표 상품과 가격 (3개까지) | 가격 노출을 원치 않으면 **"비공개"** 로 적고, 콘텐츠에 가격을 넣지 않는다 |
| 원산지 · 인증 · 자격 · 수상 | **증명서나 표시가 있는 것만.** "국내산"이면 어떤 품목이 국내산인지 |
| 시작한 연도 · 년수 | *"거의 30년"* 은 받지 않는다. 연도로 |
| 예약 · 주문 · 문의 방법 | 전화 · 네이버 예약 · 카카오채널 · 배민 중 실제로 응답하는 것만 |
| 절대 하지 않는 것 | **사실인 것만.** "조미료 안 씀"이 사실이면 적고, 가끔 쓰면 적지 않는다 |

**비워두는 걸 허용한다.** 빈칸은 ☐로 두고 `01` 파일의 「비어 있는 것」에 모은다.

---

## 업종별 규정은 조회한다 — 시트를 받은 직후

아래 표는 강사가 적은 일반 안내다. **실제 수업에서는 `research.md` ②의 규정 조회를 먼저 돌려** 이 업종의 표현 기준을 웹에서 찾고 출처와 함께 보여준다. 조회가 안 되면 아래 표로 대신한다. 조회 결과는 `[조사]`로 표기하고 사장님 확인 뒤 시트에 넣는다.

## 말하면 안 되는 것 — 시트를 받은 뒤 한 번 짚는다

```
사실 시트 고맙습니다. 하나만 같이 확인할게요.
앞으로 콘텐츠를 만들 때 이런 건 쓰지 않도록 프로젝트 지침에 넣어둘 거예요.

① 증명 못 하는 최초 · 최고 · 유일 · 1등 · No.1
② 효능 표현 — "면역력", "다이어트에 좋은", "피부가 좋아지는", "숙취 해소", "통증 완화"
③ 다른 가게와의 비교 · 비하
④ 사실 시트에 없는 숫자 — 년수, 판매량, 후기 수, 재방문율
⑤ 사진에 없는 것을 있는 것처럼 — 실제 매장 · 실제 상품 사진이 기준

이 중에 "우리는 이거 진짜 사실인데" 싶은 게 있으면 지금 알려주세요.
증명할 수 있으면 시트에 넣고, 쓸 수 있게 합니다.
```

### 업종별로 특히 걸리는 것

| 업종 | 조심할 표현 | 대신 쓸 수 있는 것 |
|---|---|---|
| **음식 · 반찬 · 카페 · 건강식품** | 효능 · 치료 · 예방 · "몸에 좋은" · "저칼로리"(수치 없이) | 재료와 조리법 **사실**, 손님이 한 말(후기 인용) |
| **미용 · 네일 · 피부 · 헤어** | "피부 재생" · "탄력 회복" · 전후 사진의 과장 | 시술 내용 사실, 소요 시간, 관리 방법 |
| **학원 · 공방 · 레슨** | 합격률 · 수강생 수(근거 없이) · "누구나 3개월이면" | 커리큘럼 사실, 실제 수강생 말(동의 받은 것) |
| **운동 · 필라테스 · 요가** | "○kg 감량 보장" · 체형 교정 효과 단정 | 수업 구성, 강사 자격(증명 가능한 것) |
| **꽃 · 소품 · 공예 · 잡화** | "수제 100%"(일부 기성품 쓰면서) · 원산지 혼동 | 만드는 과정 사실, 소재 |
| **모든 업종** | 최초 · 최고 · 유일 · 1등 · 비교 · 근거 없는 숫자 | 사실 시트의 문장 |

> 이 표는 **주의 안내**다. 법률 자문이 아니고, 최종 판단은 사장님이 한다. 다만 **증명 못 하는 말은 쓰지 않는다**는 원칙만 지키면 대부분 걸리지 않는다.

## 「손님이 한 말」을 쓸 때

C의 가치는 손님 말이다. 콘텐츠에 인용할 때는 —

- **리뷰 원문을 그대로 캡처**해 쓰는 건 공개된 리뷰면 대개 괜찮다. 이름은 가린다
- **직접 들은 말**을 인용할 때는 *"손님이 이렇게 말씀하셨어요"* 형태로. 누구인지 특정하지 않는다
- **없는 후기를 만들지 않는다.** 이건 과장이 아니라 위조다

## 프로젝트 지침에 들어가는 문장

`00_프로젝트_지침.md`에 아래가 들어간다. 사용자에게는 보여주기만 하고 고치게 하지 않는다.

```
사실 규칙
- 상호 · 주소 · 영업시간 · 가격 · 원산지 · 인증 · 년수 · 숫자는 03_사실시트.md 에 있는 것만 쓴다.

- 후기와 손님의 말은 03 또는 01 파일에 적힌 것만 인용한다. 새로 만들지 않는다.
```

# 채널 우선순위 · 세 기둥 · 1주차 3개 · 1개월 방향

STEP 7에서 읽는다. **방향만 주고 끝내지 않는다.** 「뭘 올려야 할지 모르겠다」가 막힘 1위다. 첫 주 세 개는 오늘 구체적으로 정한다. 나머지 3주는 방향까지.

---

## 1. 채널 우선순위 — 손님이 있는 곳

질문 하나로 정한다.
```
그 손님(D)은 하루 중에 언제, 어디를 보고 있을까요?
네이버 검색 · 인스타 · 카카오톡 · 스레드 · 유튜브 · 당근 · 스마트스토어 중에서요.
```

### 채널을 정한 뒤 — [조사] 검색어 · 시즌

D가 정해졌으니 손님이 실제로 칠 **검색어 5개**(지역 + 업종 + 상황)와 앞으로 석 달의 **지역 이벤트 · 시즌 3개**를 웹에서 찾는다. 검색어는 인스타 이름 칸 · 플레이스 대표 키워드 · 04 파일로, 시즌은 05의 4주 테마와 카카오채널 메시지 시점으로 들어간다. 다섯 줄, 출처, `[조사]` 표기. → `research.md` ③

### 기본형

| 채널 | 역할 | 언제 |
|---|---|---|
| **네이버 플레이스** (이미 있음) | 손님이 실제로 **찾아오는 길**. 새로 만들지 않는다 | 소개글을 오늘 문안으로 **갱신**. 10분 |
| **인스타그램 비즈니스** | 처음 보는 사람이 **발견**하는 곳 | 항상. 이름 칸에 지역 + 업종 |
| **카카오톡 채널** | 한 번 온 사람에게 **다시 말을 거는** 곳. 재구매 알림 | 재방문 · 예약 · 재구매가 매출인 업종 |
| **스레드** | 사장님 **말투로 짧게**. 사진 없이 두 줄 | 안 올리던 분의 **첫 습관**으로 가장 낮은 문턱 |

### 페르소나별 조정

| D가 이런 사람이면 | 조정 |
|---|---|
| 네이버 검색해서 오는 사람 | 플레이스 소개글 갱신을 먼저. 인스타 이름에 **지역 + 업종** 키워드 |
| 한 번 오면 계속 오는 사람 · 재구매 | **카카오채널 1순위.** 인스타는 채널 유입 통로 |
| 온라인에서만 사는 사람 (스마트스토어) | 플레이스 대신 **스토어 상세 첫 화면**의 소개 문장을 B·C로 갱신. 카카오채널은 재구매 알림 |
| 사장님 이야기에 반응하는 사람 | **스레드 권장.** 릴스(4회차)와 맞물린다 |
| 학부모 · 예약 고객 | 카카오채널 + 인스타. 스레드는 뺀다 |

### 안 할 채널 정하기

채널이 이미 4개 이상인 분에게 묻는다.
```
지금 하시는 것 중에 한 달 동안 손 안 댈 채널을 하나 고르면요?
```
**세팅이 아니라 정리가 필요한 분**이다. 「안 할 것」을 04 파일에 적는다. 셋 다 하라고 하지 않는다. **인스타 하나 + 페르소나에 맞는 하나.**

## 2. 세 기둥 — 3층이 그대로 콘텐츠가 된다

SKILL.md의 3층 표를 **오늘 채운 내용으로** 다시 보여준다.

```
오늘 채운 걸 세 기둥으로 놓으면 이렇게 돼요.

| 기둥 | 오늘 나온 것 | 어떤 콘텐츠 |
|---|---|---|
| ① 상품 · 공간 (내가 파는 것) | (F 대표 상품 · 절대 하지 않는 것) | 사실을 보여주는 사진 · 메뉴 · 공간 · 포장 |
| ② 손님의 변화 (사는 사람) | (B 한 문장 · C 가치) | 후기 · 전후 · "이런 분이 오세요" |
| ③ 사장님 (나라는 사람) | (E 말투 · 고집 · 시작한 이유) | 얼굴 · 손 · 작업 · 한마디 |

이 세 기둥으로 한 달을 갑니다. 셋 중 사장님이 제일 자신 있는 기둥은 어디예요?
```

**자신 있는 기둥이 1주차 첫 게시물이다.**

### 기둥과 2~4회차 매핑

| 기둥 | 회차 | 왜 |
|---|---|---|
| ② 손님의 변화 | **2회차 카드뉴스** | 후킹 → 공감 → 제안 → 근거 → CTA 구조가 Before/After와 맞물린다 |
| ① 상품 · 공간 | **3회차 이미지 4종** | 메뉴/제품컷 · 배너 · 프로필 · 매장 무드컷은 전부 사실 기둥이다 |
| ③ 사장님 | **4회차 릴스** | 첫 1.5초 후킹은 얼굴과 말투가 가장 세다 |

---

## 3. 1주차 게시물 3개 — 오늘 구체적으로 정한다 ★

**기둥마다 하나씩.** 기둥별로 **후보 두 개**를 낸다. 후보는 반드시 A~F에서 나온 말로. 사용자가 고르면 네 칸을 채운다.

| 칸 | 무엇 | 예 (반찬가게) |
|---|---|---|
| **주제** | 한 줄 | 무말랭이 — 조미료 없이 매일 새로 |
| **찍을 것** | 폰으로 찍을 사진 · 영상 1~2개. 구체적으로 | 아침에 무치는 손 + 담긴 통 클로즈업 |
| **형식** | 사진 1장 / 사진 3장 / 15초 영상 / 스레드 글 | 사진 2장 |
| **첫 줄** | 사장님 말투로. 02 표본 어미 | "오늘도 무말랭이는 아침에 무쳤어요" |

```
첫 주에 올릴 세 개를 지금 정할게요. 기둥마다 하나씩요.

① 상품 · 공간 — 이 둘 중에요.
   A. (F 대표 상품 1)을 (E 고집)과 함께 보여주기
   B. (F 절대 하지 않는 것)을 사진 한 장으로
② 손님의 변화 — 이 둘 중에요.
   A. "(A-① 단골의 말)" 그 말을 그대로 첫 줄로
   B. B의 Before 장면 한 컷 → After 한 줄
③ 사장님 — 이 둘 중에요.
   A. (E-③ 고집) 한 줄 + 작업하는 손
   B. (E-③ 왜 시작했나) 두 줄, 사진 없이 스레드로

어느 쪽이 편하세요? 고르시면 찍을 것과 첫 줄까지 채울게요.
```

**후보에 없는 것을 사용자가 말하면 그걸 쓴다.** 후보는 마중물이다.
**"사진 · 영상 만들기가 어렵다"는 분** — 형식을 「사진 1장」과 「스레드 글」로만 잡는다. 영상은 4회차 뒤에.

---

## 4. 촬영 리스트 — 이번 주에 폰으로 찍어올 것

「사진 만들기가 어렵다」의 절반은 **찍을 게 정해지지 않아서**다. 1주차 3개의 「찍을 것」에 아래를 더해 **10장 목록**을 만든다. 3회차 이미지 수업의 재료다.

| 출처 | 찍을 것 |
|---|---|
| F 대표 상품 3개 | 각각 1장. 자연광, 정면, 배경 단순 |
| E 「보여줘도 되는 것」 | 손 · 재료 · 작업 장면 중 2장 |
| 매장 · 포장 | 간판 또는 입구 1장 · 앉는 자리 또는 포장 상태 1장 |
| 1주차 3개의 「찍을 것」 | 그대로 |

```
이번 주에 폰으로 찍어올 사진 목록이에요. 열 장이면 3회차까지 충분합니다.
잘 찍을 필요 없어요. 밝을 때, 정면에서, 배경 단순하게. 그거면 됩니다.
```

E 「안 보여줄 것」은 목록에 넣지 않는다.

## 5. 4주 기본형

**주 1회 게시물 + 스레드 짧은 글 주 2회.** 한 달 게시물 4~6개.
현재 한 달 0개인 분이 대부분이다. 주 3회는 실패 설계다. **첫 달은 "끊기지 않는 것"이 목표**라고 말한다.

| 주차 | 기둥 | 방향 | 포맷 (회차) |
|---|---|---|---|
| **1주** | 셋 다 | 프로필 완성 + **오늘 정한 3개** | 사진 + 짧은 글 · 스레드 |
| **2주** | ① 상품 · 공간 | 대표 상품을 사실로. F 시트 문장만. 촬영 리스트 사진 사용 | 이미지 (3회차) |
| **3주** | ② 손님의 변화 | Before/After 카드뉴스 1세트. C의 말 인용 | 카드뉴스 (2회차) |
| **4주** | ③ 사장님 | 릴스 1편. 고집 하나 · 시작한 이유 | 릴스 (4회차) |

**순서는 수업 순서와 다르다.** 수업은 카드뉴스 → 이미지 → 릴스지만, 발행은 프로필과 사실부터가 안전하다. *"수업에서 만든 순서대로 올리셔도 돼요"* 라고 말한다.

### 카카오채널을 쓰는 경우

| 주차 | 카카오채널 |
|---|---|
| 1주 | 웰컴 메시지 세팅. 매장 계산대 · 포장에 채널 추가 QR |
| 3주 | 첫 메시지 1회. 새 소식 하나 (신메뉴 · 휴무 · 입고). **팔지 않는다** |

### 스레드를 쓰는 경우

| 빈도 | 내용 |
|---|---|
| 주 2회, 사진 없이 | E-① 말투로 한두 줄. 오늘 있었던 일 · 손님이 한 말 · 고집 |

# 단 컷 소개 이미지 — 프롬프트 뽑기 · 검수 · 채널별 쓰임

---

## 두 가지 길 — 사진이 있으면 사진이 먼저다

| 길 | 언제 | 어떻게 |
|---|---|---|
| **A. 내 사진 + AI 정리** (기본) | 폰에 상품 · 매장 사진이 있다 | 사진 1장을 올리고 배경 정리 · 밝기 · 여백만 손본다. **없는 것을 그려 넣지 않는다** |
| **B. AI 생성** | 사진이 없다 (창업 예정 · 온라인몰 초기) | 아래 프롬프트로 3안 생성 → 고르기 |

A가 기본인 이유 — 사실 시트 원칙과 같다. **실제 매장 · 실제 상품이 기준**이다. AI가 그린 매장은 손님이 와서 "여기가 거기예요?" 하게 만든다.

---

## 프롬프트 뽑기 — 프로젝트 파일에서

사용자가 만든 마케팅 프로젝트 안에서, 또는 이 스킬이 STEP 7 끝에 아래를 만든다.

```
01 · 02 · 03 파일 기준으로 소개 이미지 프롬프트를 영어로 3개 써줘.

규칙
- 한 문장(01의 B)의 뒷칸, 즉 "구멍"이 보이는 장면으로. 상품만 덩그러니 놓지 않는다
- 03 사실 시트에 있는 것만 그린다. 없는 간판 · 없는 인테리어 · 없는 인증 마크를 넣지 않는다
- 02의 「안 보여줄 것」은 넣지 않는다 (얼굴 · 주방 등)
- 글자는 넣지 않는다. 글자는 나중에 따로 얹는다
- 타사 로고 · 상표 없음
- 정방형(1:1), 자연광, 배경 단순, 실제 사진처럼

세 안은 구도만 다르게: ① 상품 클로즈업 ② 손이 작업하는 장면 ③ 손님이 받는 순간
```

**세 안 중 고른 뒤 사장님 말로 한 줄 고치게 한다.** 예: *"우리 포장은 종이봉투예요. 그거 넣어주세요."*

---

## 글자는 나중에, 따로

AI 이미지 안의 한글은 오기가 잦다. **이미지는 글자 없이 만들고, 한 문장과 상호는 캔바(2회차) 또는 인스타 앱의 텍스트 기능으로 얹는다.** 1회차에는 글자 없는 버전으로 채널에 올려도 된다. 소개 문장은 캡션과 프로필 소개에 이미 들어간다.

굳이 오늘 얹는다면 — 짧게, 상호 하나만. 한글 오기를 반드시 확인한다.

---

## 검수 — 올리기 전 다섯 가지

| # | 확인 | 걸리면 |
|---|---|---|
| 1 | 03 사실 시트에 없는 것이 그려졌나 (간판 · 인테리어 · 인증 · 메뉴) | 지우거나 A(내 사진)로 |
| 2 | 02 「안 보여줄 것」이 들어갔나 | 다시 생성 |
| 3 | 글자가 있으면 오기 · 깨짐 | 글자 없는 버전으로 |
| 4 | 타사 로고 · 상표 · 유명 캐릭터 | 다시 생성 |
| 5 | 이 한 장만 보고 "구멍"이 보이나 (드릴만 보이면 안 된다) | 구도 ② 또는 ③으로 |

**한 장이면 된다.** 세 장 고르느라 시간을 쓰지 않는다.

# 채널 세팅 가이드 — 문안 · 순서 · 화면이 다를 때

STEP 7-③과 STEP 8에서 읽는다. **스킬은 문안과 순서를 준다. 클릭은 사용자가 한다.**

**기준일: 2026년 9월.** 앱 화면은 자주 바뀐다. 아래 순서는 방향이고, 버튼 이름은 다를 수 있다.

---

## 화면이 다를 때 — 이 프로토콜을 먼저 말한다

세팅 안내를 시작할 때 **반드시** 이렇게 말한다.

```
지금부터 순서를 알려드릴게요. 앱 화면은 자주 바뀌어서 버튼 이름이 다를 수 있어요.
설명과 다른 화면이 나오면 그 화면을 캡처해서 올려주세요. 보고 다음 버튼을 알려드릴게요.
```

| 상황 | 대응 |
|---|---|
| *"그런 메뉴가 없어요"* | *"지금 보이는 화면 캡처해주시겠어요?"* → 캡처 기준으로 다시 안내 |
| 캡처가 왔는데 낯선 화면 | 화면의 글자를 읽고 **가장 비슷한 이름**을 짚는다. 확신 없으면 *"이 중에 '계정' 이나 '도구' 비슷한 게 있나요?"* |
| 캡처를 못 올림 | *"화면에 보이는 메뉴 이름을 위에서부터 읽어주세요"* |
| 앱 업데이트 요구 | 업데이트 후 진행. 기다리는 동안 문안을 고친다 |
| **비밀번호 · 인증번호 · 결제 화면** | **절대 대신 하지 않는다.** *"이건 사장님이 직접 입력하시고, 다음 화면 오면 알려주세요"* |

**안내를 고집하지 않는다.** 화면이 진실이다.

## A. 인스타그램 — 비즈니스(프로페셔널) 계정

### 세팅 순서 (기준일 2026-09)

```
① 인스타그램 앱 → 오른쪽 아래 프로필 → 오른쪽 위 ☰ → 「설정 및 활동」
② 「계정 종류 및 도구」 → 「프로페셔널 계정으로 전환」
③ 카테고리 선택 — 우리 업종에 가장 가까운 것 (카페 · 음식점 · 미용실 · 학원 …)
④ 「비즈니스」 선택 (크리에이터가 아니라)
⑤ 연락처 표시 여부 — 전화 · 이메일 · 주소 중 F 시트에 있는 것만
⑥ 페이스북 페이지 연결 — 오늘은 「건너뛰기」 해도 된다
⑦ 프로필 편집 → 아래 문안 입력
```

**주의** — 프로페셔널 전환하면 계정이 **공개**로 바뀐다. 비공개로 쓰던 분은 미리 말해준다.
**이미 프로페셔널이면** ①~⑥을 건너뛰고 ⑦만 한다.

### 프로필 문안 — A~F에서 나온 말로만

| 칸 | 규칙 | 재료 |
|---|---|---|
| **이름** (검색에 걸리는 칸) | `상호 · 지역 · 업종` 순. 예: `한끼반찬 · 망원동 반찬가게` | F 상호 · 주소 |
| **사용자 이름** (@아이디) | 이미 있으면 그대로. 새로 만들면 상호 영문 + 지역 | F |
| **소개** (150자) | **1줄: B 뒷칸을 사장님 말로 / 2줄: C 가치(손님 말) / 3줄: F 사실 하나(영업시간 또는 위치) / 4줄: 행동 하나(예약 · 채널 추가 · 링크)** | B · C · F |
| **링크** | 카카오채널 또는 네이버 예약 또는 플레이스 **하나**. 여러 개면 링크 모음 서비스 | F 문의 방법 |
| **카테고리** | ③에서 고른 것 | |
| **연락처** | F 시트에 있는 것만 | F |

**소개 초안은 두 개 낸다.** 하나는 사장님 말투(E-①) 그대로, 하나는 조금 정돈된 것. 사용자가 고르고 고친다.

```
예 (반찬가게)
저녁 걱정 없는 퇴근길을 만듭니다
"여기 반찬은 안 남아요" — 단골 말
망원동 · 화~토 11:00–20:00 · 월요일 휴무
▼ 카카오채널 추가하면 이번 주 반찬을 먼저 알려드려요
```

### 하이라이트 (있으면)

세 기둥에 맞춰 **세 개만** — `메뉴` · `손님` · `사장님`. 오늘은 이름만 정하고 비워둔다.

## B. 카카오톡 채널

### 세팅 순서 (기준일 2026-09)

```
① PC 브라우저에서 「카카오 비즈니스 파트너센터」 접속 (business.kakao.com)

③ 「새 채널 만들기」
④ 채널 이름 · 검색용 아이디 · 카테고리 입력 (아래 문안)
⑤ 프로필 → 프로필 설정 → 채널 정보 → 「고객센터 연락처」 등록  ← 빠뜨리면 나중에 메시지 못 보냄
⑥ 대시보드에서 「채널 공개하기」 ✔ · 「검색 허용하기」 ✔
⑦ 메시지 → 「웰컴 메시지」 → 아래 문안으로 교체
⑧ (선택) 채널 → 「비즈니스 심사」 — 사업자등록증 제출. 3~5일. V 뱃지 · 알림톡 가능
```

**⑧은 오늘 안 해도 된다.** 서류가 있으면 신청만 걸어둔다.
**사업자등록증 · 신분증 업로드는 사장님이 직접 한다.**

### 문안

| 칸 | 규칙 | 재료 |
|---|---|---|
| **채널 이름** | 상호 그대로. 20자 이내 | F 상호 |

## D. 파일 올리기와 테스트 — 프로젝트는 이미 있다

**수업은 ChatGPT 프로젝트 하나로 간다.** 참가자는 오프닝에서 「(상호) 마케팅」 프로젝트를 만들고 지침과 참조 묶음을 올린 뒤 그 안에서 인터뷰를 했다 (`chatgpt/README.md`). 그래서 STEP 8은 개설이 아니라 **파일 다섯 개를 같은 프로젝트에 올리는 것**이다.

```
① 인터뷰가 만든 01 ~ 05 다섯 파일을 내려받는다
② 지금 이 프로젝트 → 「파일」 → 다섯 개 업로드
③ 새 대화 → 테스트 질문: "우리를 손님 말로 세 줄만 소개해줘"
```

다섯 파일이 올라가면 지침이 스스로 **마케팅 모드**로 바뀐다. 지침을 바꿔 붙일 필요가 없다.

| 테스트 결과 | 뜻 | 조치 |
|---|---|---|
| 사실 시트에 있는 것만 나옴 · 사장님 말투 | 정상 | 끝 |
| 시트에 없는 숫자 · "30년 전통" 등 | 03이 안 올라감 | 03 확인 |
| 존댓말 광고체 · 이모지 남발 | 02가 안 읽힘 | 02 업로드 확인 |
| 페르소나와 다른 사람에게 말함 | 01이 안 읽힘 | 01 업로드 확인 |
| 여전히 인터뷰 질문을 함 | 파일 이름이 다르거나 덜 올라감 | 파일명 01~05 확인 |

**무료 계정** — 파일 개수 한도에 걸리면 참조 묶음을 지우고 01~05를 올린다. 인터뷰는 끝났으니 참조 묶음은 없어도 된다.
**파일이 안 내려받아지면** — 코드블록 복사 → 메모장 → `.md`로 저장. 파일명 그대로.

### 클로드인 경우
```
클로드 앱 → 「프로젝트」 → 「새 프로젝트」 → 「지침 설정」에 00 붙이기 → 「지식 추가」에 01~05 업로드 → 같은 테스트 질문
```

## E. 네이버 플레이스 — 소개글 갱신 (10분)

**새로 만들지 않는다.** 대부분 이미 있고, 손님이 실제로 찾아오는 길이다. 오늘 만든 문안으로 **소개글만 바꾼다.**

```

② 「업체 정보」 → 「소개글」 (또는 「업체 설명」)
③ 아래 문안으로 교체 → 저장
④ (있으면) 「대표 키워드」에 지역 + 업종 + 대표 상품
```

| 칸 | 규칙 | 재료 |
|---|---|---|
| **소개글 첫 줄** | B 뒷칸을 사장님 말로 | B · E |
| **둘째 줄** | C 가치 (손님 말) 또는 A-① 단골의 말 | C · A |

| **대표 키워드** | 지역 · 업종 · 대표 상품 · (예정이면 비움) | F |

## 항상 먼저 읽을 파일
- 01_가치x페르소나_시트.md — 우리가 파는 변화 · 손님 한 명 · 그 손님의 말. 모든 콘텐츠의 기준

## 콘텐츠를 만들 때
1. 요청을 받으면 먼저 01의 페르소나 한 명에게 말하는 것인지 확인한다. "모두에게"는 없다.
2. 후킹 문장은 01의 Before에서, 결론은 After에서, 근거는 03의 사실에서 가져온다.
3. 손님의 말을 인용할 때는 01의 C(가치)에 적힌 문장만 쓴다.
4. 사장님 1인칭으로 쓴다. 02의 말투 표본과 어미를 따르고, 02의 「안 쓰는 말」은 쓰지 않는다.
5. 02의 「안 보여줄 것」에 해당하는 소재(얼굴 · 주방 · 가격 등)는 제안하지 않는다.
6. 다 만든 뒤 스스로 검수한다 — 03에 없는 사실이 있나 · 최초/최고/효능/비교 표현이 있나 · 페르소나가 아닌 사람에게 말하고 있나.

## 사실 규칙
- 상호 · 주소 · 영업시간 · 가격 · 원산지 · 인증 · 년수 · 숫자는 03에 있는 것만 쓴다.
- 03에 없는 사실이 필요하면 지어내지 말고 [확인 필요: ○○] 로 표시한다.
- 최초 · 최고 · 유일 · 1등 · 효능 · 다른 가게와 비교 · 근거 없는 숫자는 쓰지 않는다.
- 후기와 손님의 말은 01 또는 03에 적힌 것만 인용한다. 새로 만들지 않는다.
{업종별 주의 표현 — facts-sheet-guide.md 의 해당 업종 줄}

## 대화 방식
- 한 번에 한 가지만 묻는다.
- 사장님이 "모르겠다"고 하면 답을 대신 쓰지 않고, 01~05에서 힌트가 될 줄을 보여준다.
- 초안을 낼 때는 2~3개를 내고 사장님이 고르고 고치게 한다. 확정하지 않는다.
- 아이템(메뉴 · 상품)을 바꾸라고 제안하지 않는다. 무엇을 앞세울지만 제안한다.

## 이 프로젝트가 하지 않는 것
- 사실을 지어내지 않는다.
- 없는 후기를 만들지 않는다.
- 타사 로고 · 상표가 들어간 이미지를 만들지 않는다.
- 다른 가게를 언급하거나 비교하지 않는다.

## 반찬가게 · 6년차 · 망원동

### 0. 소개
반찬 15종 매일 조리 · 망원동 골목 매장 + 카카오 주문 · 6년 · 인스타 개인 계정에 가끔 사진

### A · 재료

| | |
|---|---|
| 단골이 소개할 때 하는 말 | **"거기는 반찬이 안 남아"** · "조미료 안 쓰는 집" |
| 처음 온 사람이 묻는 것 | "이거 며칠 가요?" · "혼자 살면 몇 개 사요?" |
| 한 번 오고 안 오는 이유 | (짐작) 마트보다 비싸다고 느낌 · 주차 안 됨 |
| 리뷰에 반복되는 말 | "간이 세지 않아서 좋아요" · "양이 적어요" |
| 지금 채널 | 인스타 개인 · 네이버 플레이스 |

### B · 변화

| | |
|---|---|
| 가장 만족한 손님이 얻어 간 것 | 퇴근하고 밥만 하면 되는 저녁 |
| **Before** | 퇴근길에 뭐 먹을지 매일 고민. 배달 시키고 죄책감 |
| **After** | **밥만 하면 저녁이 됨.** 배달 앱을 덜 켬 |
| 대안 | 배달. 아니면 대충 라면 |
| 대체 불가 — 우리 쪽 기준 | 매일 아침 새로 함. 조미료 안 씀. 1인분 소포장 |

**테스트** — 손님 입에서 나올 말인가 ⭕ · 손님을 4인 가족 주부로 바꾸면 바뀌는가 ⭕ (*"애들이 골고루 먹어요"* 가 될 것) · 옆 반찬가게도 할 수 있는 말인가 — "배달 앱을 안 켜게" 는 이 손님과 이 가게의 조합에서만 나온다 ⭕

### E · 사장님
| | |
|---|---|
| 말투 표본 (대화에서) | *"그냥 매일 새로 해요"* · *"저는 그거 안 해요"* · *"먹어보면 알아요"* |
| 안 쓰는 말 | "엄마 손맛" · "집밥 감성" · 이모지 |

| | |
|---|---|
| 영업시간 | 화~토 11:00–20:00 · 월 휴무 |

### 채널 · 방향
- 인스타 필수 · **카카오채널 1순위** (재구매가 매출) · 스레드 권장 (말투가 산다)
- 자신 있는 기둥: ① 상품 → 1주차
- 2회차 카드뉴스: *"배달 앱을 켰다가 닫은 밤"* 에서 시작 → *"밥만 하면 되는 저녁"* 으로

> **이 케이스의 발견**
> 사장님은 처음에 *"조미료 안 쓰는 반찬을 판다"* 고 했다. 그건 **우리 쪽 기준의 대체 불가**고, 변화가 아니다.
> 가장 만족한 손님 이야기를 꺼내자 *"밥만 하면 된다"* 가 나왔다. 조미료는 **왜 우리인가**의 근거로 내려갔고, 변화는 **저녁이 해결된다**로 올라갔다.
> **아이템(반찬)은 하나도 안 바꿨다. 앞세우는 것만 바뀌었다.**

| 가치 | *"매일 새로 만든 신선한 반찬"* | 사장님 말 | *"손님이 친구한테 카톡으로 보낼 말로요"* |
| 가치 | *"밥만 하면 저녁이 돼요"* | 변화 복붙 | *"그건 우리가 정한 변화고, 손님은 뭐라고 할까요?"* |
| 가치 | *"망원동 집밥, 오늘 저녁 해결하세요"* | 카피 | *"그건 광고예요. 다음 회차에 만들어요"* |
| 페르소나 | *"동네 주민 다요"* | 상황 없음 | *"우리가 없으면 제일 아쉬워할 한 분은요?"* |

## 설문에서 온 업종 — 짧은 예시 세 개 (v0.2 추가)

| 상황 | 한 문장 | 손님(D) | 그 손님의 말(C) | 비고 |
|---|---|---|---|---|
| **온라인몰 · 스마트스토어** (매장 없음) | 운동복을 파는 게 아니라, **사이즈 고민 없이 결제 버튼을 누르는 10초**를 판다 | 온라인에서 옷 사고 두 번 반품한 40대 | *"여긴 사이즈표가 진짜 맞아요"* (재구매 후기) | 단골의 말 → 재구매 후기, 처음 질문 → Q&A, 안 사는 이유 → 반품 사유 |
| **주문형 떡공방** (SNS · 전화 주문, 픽업 · 퀵) | 떡을 파는 게 아니라, **답례 고민이 끝나는 한 통의 카톡**을 판다 | 돌잔치 · 개업 답례 준비하는 30대 | *"카톡으로 사진 하나 보내니까 알아서 해주셨어요"* | 대안이 "인터넷 대량 주문 또는 안 함". 카카오채널이 주문 창구 |
| **창업 예정 · 팔 것은 정함** (꽃 · 공방) | 꽃 수업을 파는 게 아니라, **평일 저녁 두 시간 아무 생각 안 하는 시간**을 판다 | 퇴근 후 뭔가 배우고 싶은데 부담은 싫은 30대 | *(짐작)* *"손만 움직이니까 머리가 비어요"* — 첫 손님 3명에게 확인 | A′ 예정 재료: 본인이 손님이었을 때 "수업이 너무 진지해서 부담"이 Before가 됨 |

**온라인몰의 핵심** — "지나가다가"가 없다. Before는 **화면 앞에서 망설이는 장면**이고, 대체 불가의 우리 쪽 기준은 배송 · 사이즈표 · 상세 사진 같은 **화면에서 확인되는 것**이다.
**주문형의 핵심** — 카카오채널이 SNS가 아니라 **주문 창구**다. 웰컴 메시지가 곧 주문 안내다.
**창업 예정의 핵심** — C는 짐작이다. 지어내지 말고 「짐작」이라고 쓰고, `01`의 「비어 있는 것」에 *"첫 손님 3명에게 듣기"* 를 넣는다.

## 1. 2~4회차는 첫 질문을 다시 하지 않는다

1회차 파일 여섯 개가 **인터페이스**다. 이후 회차 스킬은 프로젝트 안에서 이 파일을 읽고 시작한다.

| 회차 | 산출물 | 읽는 파일 | 첫 질문 대신 |
|---|---|---|---|
| **2회차 카드뉴스** | 발행 가능한 카드뉴스 1세트 · 재사용 카드뉴스 스킬 | 01 (B Before/After · C) · 02 · 03 · 05 | 05의 「2회차」 줄. 후킹은 Before, 결론은 After, 근거는 03 |
| **3회차 이미지** | 용도별 이미지 4종 · 브랜드 이미지 프롬프트 스킬 | 02 (보여줘도 되는 것 · 안 보여줄 것) · 03 · 05 | ① 기둥. 메뉴/제품컷 · 배너 · 프로필 · 매장 무드컷 |
| **4회차 릴스** | 완성 릴스 1편 · 릴스 기획 스킬 | 02 (말투 · 고집) · 01 (C) · 05 | ③ 기둥. 첫 1.5초는 E의 고집 한 줄 |

**검수는 전부 03 사실 시트 기준.** 시트 밖의 숫자 · 효능 · 최초/최고가 나오면 그 줄을 지운다.

### 2회차 스킬을 만들 때 지킬 것
- 프로젝트에 01~05가 있으면 **읽고 요약해서 확인만** 받는다 — *"제가 이렇게 이해했는데 맞나요?"*
- 없으면 세 가지만 묻고 시작한다 — 누구에게 · 무엇이 달라지나 · 사실 하나
- 카드뉴스 원고의 **후킹 → 공감 → 제안 → 근거 → CTA** 는 01의 Before → 대안 → After → 03 사실 → 04 채널 행동과 1:1로 맞는다

## 3. 검증 숙제 — 수업에서 돌리지 않는다

> **`virtual-customer-feedback-qa`**
> github.com/selfishclub/virtual-customer-feedback-qa
> 한국인 합성 페르소나 5명에게 직접 물어보는 스킬. 10분.

**1회차 수업 시간에는 제안하지 않는다.** 시간이 없고, 프로젝트 개설과 채널 세팅이 우선이다.
마무리 숙제로 **한 번만** 말한다.

```
집에서 하나 더 해보실 분만요.
오늘 만든 01번 파일을 가상 손님 5명한테 한번 보여볼 수 있어요.

  github.com/selfishclub/virtual-customer-feedback-qa

01번 파일을 그대로 넣으면 되고, 10분이면 끝나요.
전체를 바꾸라는 게 아니고, "어 이건 생각 못 했네" 하나 건지면 충분합니다.
```

**넘기는 프롬프트**
```
01_가치x페르소나_시트.md 로 가상 고객 피드백 받아보고 싶어.

한 문장: (B)
페르소나: (D)
가치: (C)

핵심 2 · 경계 2 · 비사용자 1로 패널 짜서 갈지 안 갈지, 왜 그런지 물어봐줘.
비사용자는 「대안」이 "그냥 안 한다 / 배달 시킨다"인 사람으로.
내가 놓친 지점이 있으면 그걸 중심으로 정리해줘.
```

## 4. 아이템을 바꾸고 싶어지면

인터뷰 중에 *"메뉴를 바꿔야 하나요"* 가 나올 수 있다. 오늘은 바꾸지 않는다.

```
오늘은 아이템을 안 바꿉니다. 뭘 앞세울지만 정해요.
한 달 콘텐츠를 돌려보고, 그때도 "전달이 아니라 이유가 틀렸다"가 계속 나오면
그때 아이템을 다시 봐요. 지금 바꾸면 뭐가 틀렸는지 알 수 없어요.
```

굳이 정하겠다고 하면 원본 스킬(`sponge-gtm-core/references/next-steps.md`)의 조건 넷만 알려준다 — 지금 만들 수 있나 · 변화를 진짜 일으키나 · 받은 사람에게 다시 말을 걸 수 있나 · 틀렸을 때 버릴 수 있나.
