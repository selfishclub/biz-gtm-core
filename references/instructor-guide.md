# 강사용 진행 가이드 — 1회차 하루 (v0.2 · 사전 설문 반영)

**대상** — 소상공인 20~30명. 사전 설문 8명 기준으로 짠 배분이다. 응답이 더 모이면 `course/설문_반영_기획노트.md`의 「다시 볼 것」을 보고 고친다.
**도구** — ChatGPT (전원 계정 보유 · 유료 3 · 무료 5). **프로젝트 하나.** 오프닝에서 만들고 지침 + 참조 묶음을 붙인다 → `chatgpt/README.md`
**목표** — 퇴장할 때 손에 들고 나가는 것 셋: **가치×페르소나 시트 · ChatGPT 프로젝트 · 1개월 콘텐츠 방향(1주차 3개 포함).**

이 파일은 사용자에게 보여주는 파일이 아니다. **강사가 읽는다.**

| 2회차 결석 예정 1명 (온라인몰 1명) | 마무리에서 개별 처리 |

## 오프닝에서 꼭 말할 것

1. **"여러분 대부분 아이템이 있으세요. 오늘은 그걸 바꾸는 날이 아니에요. 그게 누구의 무엇을 바꾸는지 적는 날이에요."**
2. **"아직 오픈 전이거나 정하는 중인 분도 같은 흐름으로 갑니다. 질문만 조금 달라요."**
3. **"모르겠다고 치셔도 됩니다. 빈칸은 다음 주에 손님한테 물어볼 목록이 돼요."**
4. **"AI가 써준 문장을 그대로 확정하지 마세요. 꼭 사장님 말로 한 번 고치세요."**
5. **"계정 비밀번호, 인증번호는 AI한테 절대 알려주지 마세요. 그건 직접 치세요."**
6. 3층 구조 그림 → 세 기둥 → **"오늘 채운 게 그대로 첫 주 게시물 세 개가 됩니다"**
7. **"한 달 목표는 많이 올리는 게 아니라 끊기지 않는 거예요. 주 1회."**

## 자주 막히는 지점과 개입 문구

| 지점 | 증상 | 강사 개입 |
|---|---|---|
| STEP 0 세 상태 | 자기 상태를 못 고름 | *"지금 돈 받고 판 적 있으면 1번, 팔 건 정했는데 아직이면 2번"* |
| 미정 (씨앗 찾기) | 후보를 다 거절 | 강사가 옆에서 *"공짜로 해준 적 있는 거 하나만요"* 로 같이 캔다. 3회 뒤엔 강사가 후보 하나 잡아준다 |
| A-③ 안 오는 이유 | 전원 "모르겠어요" | *"모르는 게 정상이에요. 짐작으로 하나만 치고 넘어가세요. 그게 오늘 숙제가 됩니다"* |
| A′ 예정 재료 | "써본 사람 없어요" | *"없어요"로 넘어가게. C는 짐작으로 표시된다고 안심시킴 |
| B-② Before/After | 메뉴 설명이 나옴 | 옆 사람 페어: *"옆 분한테 '그래서 손님 하루에서 뭐가 달라져요?' 한 번 물어보세요"* |
| B-⑤ 한 문장 | AI 초안을 그대로 확정 | *"셋 중 하나 고르셨으면 사장님 말로 한 단어라도 바꾸세요"* |
| D 페르소나 | "다요" | *"지난달 계산하면서 제일 기분 좋았던 손님 한 분요"* |
| C 가치 | 사장님 말이 나옴 | *"그 손님이 친구한테 카톡으로 뭐라고 보낼까요"* · *"네이버 리뷰에 있는 문장 그대로 가져오세요"* |
| E-① 말투 | "저는 말투가 없어요" | *"지금 AI한테 친 문장 세 개가 화면에 있어요. 그게 말투예요"* |
| F 사실 시트 | 부풀림 ("거의 30년") | *"정확한 연도로요. 시트는 증명할 수 있는 것만"* |
| STEP 7 1주차 3개 | "다 좋은데요" · 못 고름 | *"손님 한 분 떠올리면 그분이 멈춰서 볼 건 어느 쪽이에요?"* |
| STEP 7 촬영 리스트 | "사진을 못 찍어요" | *"잘 찍을 필요 없어요. 밝을 때 정면에서. 열 장이면 3회차에 AI가 다듬어요"* |
| 채널 4개 이상인 분 | 다 하려고 함 | *"한 달 손 안 댈 채널 하나만 고르세요"* |
| 파일 생성 | 파일이 안 내려받아짐 | 코드블록 복사 → 메모장 → `.md`로 저장. 파일명 그대로 |
| ChatGPT 프로젝트 | 파일이 다 안 올라감 (무료) | 참조 묶음을 지우고 01~05 올린다. 그래도 안 되면 01·02·03 먼저 |
| ChatGPT 프로젝트 | 「프로젝트」 메뉴 없음 | 웹(chatgpt.com)으로. 없으면 새 대화에 지침 붙이고 참조 묶음 첨부 |
| [조사] | 웹 검색이 안 되는 계정 | 강사 표(facts-sheet-guide 업종별 표)로 대체. 검색어·시즌은 강사가 미리 조회한 것을 공유 |
| [조사] 규정 | "우리는 진짜 천연인데요" | 인증 · 증명이 있으면 시트에 넣고 쓰게. 없으면 「천연원료로 만드는」까지 |
| 인스타 전환 | 화면이 안내와 다름 | *"AI한테 캡처 올리고 '이 화면에서 다음 어디 눌러요?' 물어보세요"* |
| 카카오채널 | 파트너센터 가입 막힘 | 카카오 계정 비밀번호 문제가 대부분. 본인 폰으로 재설정 |

## 체크포인트 운영

- **손들기**로 진도를 본다. 절반 넘으면 다음으로, 절반 안 되면 5분 더
- 진도 빠른 분에게 **"옆 분 한 문장 들어주기"** 역할을 준다
- **미정 1명**은 STEP 0~1 사이 강사가 15분 붙는다. 그 시간 나머지는 A 재료 진행 중이라 손이 빈다
- **한 문장 낭독**은 강제하지 않는다. 낭독할 때마다 *"그래서 뭐가 달라지나요?"* 를 한 번 되묻는다
- **1주차 첫 게시물 소개**는 짧게. *"첫 줄만 읽어주세요"*

## 프로젝트 테스트 질문 — 전원 같은 걸로

```
우리를 손님 말로 세 줄만 소개해줘
```

| 결과 | 진단 |
|---|---|
| 시트 안의 사실 · 사장님 말투 · 손님 말 인용 | 정상 |
| "30년 전통", "최고의" 등 | 00 지침이 안 붙었거나 03이 안 올라감 |
| 광고체 · 이모지 | 02가 안 읽힘 |
| 페르소나와 다른 사람에게 말함 | 01이 안 읽힘 |

## 마무리에 꼭 말할 것

1. **"오늘 세운 건 오늘 기준이에요. 바뀝니다."**
2. 반응 없을 때 세 갈래 — 사람 / 이유 / 전달. **"SNS는 우리랑 안 맞네"로 뭉치지 않기**
3. **촬영 숙제** — 05 파일의 촬영 리스트 10장. 3회차 전까지. *"잘 찍을 필요 없어요"*
4. **2회차는 이 프로젝트 안에서 시작한다.** 첫 질문 다시 안 한다. 05 파일의 「2회차」 줄이 첫 카드뉴스 주제
5. **2회차 결석 예정자(온라인몰 1명)** — 05의 「2회차」 줄과 01 파일을 확인시키고, 2회차 산출인 「재사용 카드뉴스 스킬」 파일을 3회차 시작 전에 단톡방으로 받게 한다. 3회차 시작 15분 전에 강사가 5분 브리핑
6. **숙제 (선택)** — A-③ 빈칸: 이번 주 손님 세 분에게 *"어떻게 알고 오셨어요?"* · 가상 고객 검증은 원하는 분만
7. **파일 여섯 개 저장 위치 확인하고 퇴장**
