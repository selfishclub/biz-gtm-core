# ChatGPT에서 이 스킬을 돌리는 방법 (강사용)

수업 도구는 ChatGPT다. 참가자는 **커스텀 GPT 링크만 열면** 된다. 강사가 전날 아래대로 만든다.

## 1. 커스텀 GPT 만들기 (기본)

```
① ChatGPT → 왼쪽 「GPT 탐색」 → 오른쪽 위 「만들기」 (ChatGPT Plus 이상 필요)
② 「구성」 탭
   - 이름: 비즈니스 GTM 코어
   - 설명: 내 비즈니스가 누구의 무엇을 바꾸는지 20개 질문으로 적고, 마케팅 프로젝트 파일 6개를 만듭니다
   - 지침: 커스텀GPT_지침.md 내용을 전부 붙여넣기 (8,000자 이내로 맞춰져 있다)
   - 대화 시작 문구: "비즈니스 GTM 코어 시작할게요" / "창업 준비 중인데 시작할게요"
③ 「지식」 → 파일 업로드: ../references/ 안의 9개 .md 전부
   (interview-guide · hint-playbook · facts-sheet-guide · content-direction · channel-setup-guide ·
    project-files-template · examples · next-steps · instructor-guide는 빼도 된다)
④ 「기능」 — 웹 브라우징 끄기 · 이미지 생성 끄기 · 코드 인터프리터 및 데이터 분석 **켜기** (파일 여섯 개를 내려받게 만들려면 필요)
⑤ 「만들기」 → 공유 범위 「링크가 있는 모든 사용자」 → 링크 복사 → 단축 URL로 단톡방 공지
⑥ 무료 계정으로 로그인한 다른 기기에서 링크를 열어 실제로 동작하는지 확인
```

**지침 글자 수** — ChatGPT 지침 한도는 8,000자다. `커스텀GPT_지침.md`는 그 안에 맞춰져 있다. 고칠 때 넘기면 「말투」 절부터 줄인다. 「절대 규칙」과 「진행 순서」는 줄이지 않는다.

**지식 파일이 검색되지 않는 것처럼 보이면** — 지침 첫 줄에 이미 "질문은 반드시 지식 파일을 검색해 그 문장 그대로 쓴다"가 있다. 그래도 GPT가 질문을 지어내면 대화 시작 문구를 "interview-guide.md의 STEP 0부터 시작해줘"로 바꾼다.

## 2. 예비 — 프로젝트 지침으로 붙이기

커스텀 GPT를 못 쓰는 상황(공유 링크 차단 · 만들기 권한 없음)이면 참가자가 직접:

```
① ChatGPT → 「프로젝트」 → 「새 프로젝트」 → 이름: GTM 코어 인터뷰
② 「지침」에 커스텀GPT_지침.md 붙여넣기
③ 「파일」에 references/ 9개 업로드 (무료 계정 한도에 걸리면 interview-guide · hint-playbook · content-direction · project-files-template 4개만)
④ 새 대화: "비즈니스 GTM 코어 시작할게요"
```

이 방식은 참가자마다 15분이 든다. 커스텀 GPT가 기본이다.

## 3. 산출물이 갈 곳은 별도 프로젝트다

인터뷰를 돌리는 GPT(또는 프로젝트)와 **산출물 여섯 개를 넣는 「(상호) 마케팅」 프로젝트는 다르다.** 인터뷰가 끝나면 GPT가 파일 여섯 개를 주고, 참가자는 새 프로젝트를 만들어 거기 넣는다. 2~4회차는 그 마케팅 프로젝트 안에서 진행한다. → `../references/channel-setup-guide.md` D절

## 4. 클로드로 리허설할 때

`SKILL.md`가 원본 규격이다. 클로드 코드에서 `~/.claude/skills/biz-gtm-core`로 링크돼 있으면 "비즈니스 GTM 코어 잡아줘"로 발동한다. 강사가 질문 흐름을 점검할 때는 이쪽이 빠르다.

## 5. 두 버전을 함께 고치는 규칙

- 질문 문장 · 양식 · 규칙은 `references/`에만 있다. GPT 지침은 **순서와 원칙만** 담는다
- `references/`를 고치면 GPT 「지식」에 다시 업로드한다. 지침은 안 바꿔도 된다
- `SKILL.md`의 STEP 구조를 바꾸면 `커스텀GPT_지침.md`의 「진행 순서」도 같이 고친다
