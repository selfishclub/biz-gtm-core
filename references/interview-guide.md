# 인터뷰 가이드 — 가게 버전 질문 전문

**한 번에 한 질문.** 전체 **19~20개**, 약 90분.

| 단계 | 블록 | 질문 수 |
|---|---|---|
| 0 | 가게 소개 + 상태 확인 | 1~2 |
| 1 | A · 재료 (또는 예정 재료 / 씨앗 찾기) | 4 |
| 2 | B · 변화 | 6 (대체 불가가 2칸) |
| 3 | D · 페르소나 | 2 |
| 4 | C · 가치 | 1 |
| 5 | E · 사장님 | 3 |
| 6 | F · 사실 시트 (표 1회) | 1 |
| 7 | 채널 · 기둥 · 1주차 3개 | 3 |
| **합계** | | **20~21** |

시간이 없으면 **E-③ · A-④** 를 먼저 뺀다. B와 D와 C, 1주차 3개는 빼지 않는다.

---

## 0. 가게 소개 — 그리고 세 상태

```
먼저 가게 소개를 짧게 해주세요. 네 가지만요.

① 무엇을 파세요? (대표 상품·메뉴·서비스 한두 개) — 예정이면 팔려는 것
② 어디서요? (동네·온라인·배달 등)
③ 몇 년 하셨어요? — 예정이면 "예정"
④ 지금 하고 있는 SNS나 채널이 있으세요?
   (인스타·네이버 플레이스·배민·스마트스토어·카카오채널·블로그·당근 등)
```

**소개에서 세 상태 중 하나를 읽는다.** 읽히면 되묻지 않는다. 안 읽히면 한 번 묻는다.

```
지금 어느 쪽에 가까우세요?
1) 지금 팔고 있다
2) 팔 것은 정했는데 아직 손님은 없다 (오픈 전 · 새 아이템 준비)
3) 뭘 팔지 아직 정하지 않았다
```

| 상태 | 어떻게 가나 |
|---|---|
| **1 팔고 있다** | 아래 STEP 1 「A · 재료」 그대로 |
| **2 팔 것은 정했다 · 손님 없음** | STEP 1을 **「A′ · 예정 재료」** 로 바꾼다. 나머지는 같다 |
| **3 미정** | **「씨앗 찾기」 3문항** → 후보 고르기 → 상태 2로 합류. 강사에게 알린다 |

**세 상태 모두 이 스킬 안에서 끝낸다.** 다른 스킬로 보내지 않는다. 수업 중에 보내면 그 사람은 혼자가 된다.

| 이런 답이 오면 | 이렇게 |
|---|---|
| 상품이 다섯 개 이상 나열 | *"그중 매출이나 손님 반응이 제일 큰 하나만 오늘의 기준으로 잡을게요. 어떤 거예요?"* |
| 온라인만 판다 (스마트스토어 · 자사몰) | 아래 A 문항의 **「온라인이면」** 문구로 바꿔 묻는다 |
| ④에 채널이 4개 이상 | *"많이 하고 계시네요. 오늘은 그중 '안 할 것'도 정할 거예요"* 예고 |
| ④에 SNS가 있음 | *"나중에 반응 제일 좋았던 게시물 하나 여쭤볼게요"* 예고 |

## 1. A · 재료 — 팔고 있는 분

```
① 단골이 다른 사람한테 우리 가게 소개할 때 뭐라고 하나요? 들은 말 그대로가 제일 좋아요.
   (온라인이면) 두 번 이상 산 분이 후기나 문의에 뭐라고 쓰나요?
```
```
② 처음 온 손님이 꼭 묻는 게 있어요?
   (예: "여기 뭐가 맛있어요?", "주차 돼요?", "혼자 와도 돼요?", "초보도 돼요?")
   (온라인이면) 스토어 Q&A나 톡톡으로 제일 많이 오는 질문이 뭐예요?
```
```
③ 한 번 오고 다시 안 오는 분들은 왜 안 올까요? 짐작이라도 괜찮아요.
   (온라인이면) 장바구니에 담고 안 사는 분, 한 번 사고 안 사는 분, 반품하는 분은 왜일까요?
```
```
④ 리뷰(네이버·배민·구글·스마트스토어)에 반복해서 나오는 칭찬이나 불만이 있어요?
   기억나는 문장이 있으면 그대로요.
```

| 이런 답이 오면 | 이렇게 되묻는다 |
|---|---|
| ① *"맛있다고 해요"* | *"맛있다 다음에 뭐라고 하나요? '~라서 맛있다' 의 뒷부분요"* |
| ② *"그냥 뭐가 맛있냐고요"* | *"그 질문을 하는 분은 어떤 상태일까요? 뭘 모르고 뭘 걱정해서 물을까요?"* |
| ③ *"모르겠어요"* | *"위치, 가격, 기대와 달랐던 것 중에 하나 골라보면요?"* 한 번만. 그래도 없으면 ☐ |
| ④ *"리뷰가 별로 없어요"* | *"그럼 직접 들은 말로요. 계산할 때 손님이 한 말 같은 거"* |

## 1′. A′ · 예정 재료 — 팔 것은 정했는데 손님이 없는 분

**손님의 말이 없으니 사장님 본인과 주변에서 캔다.** 네 문항, 같은 자리에 들어간다.

```
① 왜 이걸 팔기로 하셨어요? 계기가 된 일이 있었나요?
```
```
② 사장님이 이걸 사는 손님이었을 때, 뭐가 불편했어요? 어디서 사셨어요?
```
```
③ 이걸 이미 써본 사람(가족 · 친구 · 시장 테스트)이 있으면, 그 사람이 뭐라고 했어요?
   없으면 "없어요"도 괜찮아요.
```
```
④ 참고하는 가게나 계정이 있어요? 거기 손님들은 뭘 좋아하는 것 같아요?
```

| 문항 | 어느 칸의 재료가 되나 |
|---|---|
| ① | E-③ 왜 시작했나 · B-④ 사장님 기준 |
| ② | **Before** · 대안 |
| ③ | C 가치의 첫 후보 (실제 들은 말) |
| ④ | D 페르소나 · 채널 |

**B에서 바뀌는 것 하나** — B-① 「가장 만족한 손님」을 이렇게 묻는다.
```
이걸 받으면 제일 좋아할 사람 한 명을 떠올려보세요. 아는 사람이어도 돼요.
그 사람은 뭘 얻게 되나요?
```
나머지 B-② ~ ⑤, D, C는 그대로. **C 가치는 「짐작」으로 표시**하고 `01`의 「비어 있는 것」에 *"첫 손님 3명에게 실제로 듣기"* 를 넣는다.

## 1″. 씨앗 찾기 — 뭘 팔지 미정인 분

원본 `sponge-gtm-core` 유형 1의 축약판. **3문항 → 후보 3개 → 고르기 → 상태 2로 합류.**

```
① 지금 하고 계신 일, 또는 잘 아는 분야가 뭐예요?
```
```
② 사람들이 사장님한테 자꾸 물어보는 게 있어요?
```
```
③ 돈 받고 한 적은 없는데, 공짜로 해준 적 있는 건 뭔가요?
```

```
말씀하신 것들을 보니 이런 게 재료가 될 수 있겠어요.

1. ○○○
2. ○○○
3. ○○○

이 중에 "이건 좀 해볼 만한데" 싶은 게 있으세요? 없으면 다른 각도로 다시 뽑아볼게요.
```

- 후보는 **반드시 본인이 말한 재료에서**. 일반적인 창업 아이템을 제시하지 않는다
- *"없다"* 면 다른 각도로 **최대 3회**. 그 뒤엔 ①~③으로 돌아가 더 캔다
- 골랐으면 *"오늘은 이걸 기준으로 갈게요. 바뀌어도 돼요"* 하고 **A′ 예정 재료**로 간다
- **강사에게 알린다.** 이 분기는 시간이 더 걸린다

## 2. B · 변화

```
① 지금까지 온 손님 중에 "이분은 진짜 우리 가게 잘 왔다" 싶었던 한 분을 떠올려보세요.
   그분은 우리 가게에서 뭘 얻어 갔나요?
   (손님 없음) 이걸 받으면 제일 좋아할 사람 한 명을 떠올려보세요. 그 사람은 뭘 얻게 되나요?
```
```
② 그분이 우리 가게에 오기 전엔 어떤 상태였을까요? (Before)
   다녀간 뒤엔 뭐가 달라졌나요? (After)
```
```
③ 우리 가게에 안 오면, 그분은 대신 어떻게 하나요?
```
```
④-1 왜 하필 우리 가게여야 하나요?
     먼저 「가게 기준」으로요. 재료 · 만드는 방식 · 시간 · 위치 · 가격 · 공간 · 배송 같은 것.
```
```
④-2 이번엔 「사장님 기준」으로요.
     사장님이라서 되는 게 있다면요?
     자격 · 년수 · 직접 하는 것 · 전에 했던 일처럼 확인 가능한 것으로요.
```
```
⑤ 이걸 한 문장으로 만들어볼게요.

   "우리 가게는 ___를 파는 게 아니라, ___를 판다"

   제가 초안 세 개를 드릴 테니 고르시거나 고쳐주세요.
```

| 이런 답이 오면 | 이렇게 되묻는다 |
|---|---|
| ① 메뉴 이름만 | *"그 메뉴를 먹고 그분한테 뭐가 남았을까요?"* |
| ② 기능 · 공정 설명 | *"그건 우리가 하는 일이고, 그래서 그분 하루에서 뭐가 달라졌나요?"* |
| ③ 경쟁 가게 이름 | *"거기 가는 것 말고, 아예 안 가는 경우는 없어요? 집에서 해결하거나"* |
| ④-1 *"퀄리티가 달라요"* | *"손님이 그걸 어떻게 알아채나요? 보이는 것으로요"* |
| ④-2 *"정성 · 진심 · 열정"* | *"손님이 그걸 어떻게 알아채나요? 자격이나 년수나 직접 하는 일 같은 걸로요"* |
| ④-2 답이 없음 | ☐로 두고 넘어간다. 사장님 칸은 비어도 된다 |
| ⑤ 세 칸으로 벌어짐 | *"둘 중 하나만 남기면요? 나머지는 조건으로 한 줄 덧붙일게요"* |

**한 문장 초안을 낼 때** — Before 마지막 줄과 After 마지막 줄을 맞물린다. 세 초안은 **뒷칸의 추상도**를 다르게 한다(구체 · 중간 · 넓게). 사용자가 고른 뒤 **본인 말로 고치게** 한다.

## 3. D · 페르소나

```
① 이 변화를 가장 바라는 손님을 한 분으로 좁히면 누구예요?
   지난달 오신 분 중에 제일 잘 맞았던 한 분을 떠올려도 됩니다.
   (손님 없음) 아까 떠올린 그 사람이어도 돼요. 그분을 조금 더 그려볼게요.
```
```
② 그분은 우리 가게에 오기 직전에 뭘 하고 있었을까요? 뭐가 막혀서 왔을까요?
```

| 이런 답이 오면 | 이렇게 되묻는다 |
|---|---|
| *"다요"* · *"동네 주민"* | *"그중에 우리 가게 없으면 제일 아쉬워할 한 분은요?"* |
| *"30대 여성"* | *"그분이 오기 직전에 뭘 하다가 왔을까요?"* (②로 바로) |
| 두 명이 나옴 | *"오늘은 한 분만요. 나머지 한 분은 적어두고 나중에 가치를 따로 씁니다"* |

## 4. C · 가치

```
그분이 우리 가게 다녀가고 주변에 뭐라고 말할까요?
"거기 가보니까 ___" — 뒤를 채워주세요.
실제로 들은 말이 있으면 그 말 그대로가 제일 좋아요. 네이버 리뷰 문장도 됩니다.
```

| 이런 답이 오면 | 왜 | 이렇게 |
|---|---|---|
| *"재료가 신선해요"* | 사장님 말 | *"손님이 그걸 느꼈을 때 실제로 뭐라고 할까요?"* |
| B의 뒷칸을 그대로 | 변화 복붙 | *"그건 우리가 정한 변화고, 손님은 그걸 자기 말로 뭐라고 할까요?"* |
| *"맛있어요"* | 옆 가게도 가능 | *"옆 가게 손님도 똑같이 말할 수 있는 말이에요. 우리 가게에서만 나올 말은요?"* |
| *"믿고 먹는 집, 지금 방문하세요"* | 카피 | *"그건 광고 문구예요. 손님이 친구한테 카톡으로 보낼 말로요"* |

막히면 → `hint-playbook.md`의 「가치에서 막힐 때」. **첫 힌트 출처는 네이버 리뷰 문장.**

## 5. E · 사장님

```
① 지금까지 저한테 설명하시면서 이렇게 쓰셨어요.

     "(대화에서 사용자가 실제로 친 문장 1)"
     "(문장 2)"
     "(문장 3)"

   이게 사장님 말투예요. 손님한테 실제로 자주 하는 말도 한두 개 더 있으면 알려주세요.
```
```
② 절대 안 쓰는 말이나 싫어하는 표현이 있어요?
   (예: "핫플", "인생 맛집", 이모지 남발, 반말, "~하는 중")
   그리고 SNS에 안 올리고 싶은 것도요. (얼굴 · 주방 · 가격 · 가족 · 매출 등)
```
```
③ 이 장사를 왜 시작하셨어요?
   그리고 남들은 안 하는데 사장님은 꼭 지키는 게 하나 있다면요?
   각각 한 문장씩만요.
```

**①에서 채집할 문장 고르는 기준** — 짧고, 구어체고, 사장님 특유의 어미나 단어가 있는 것. 정중한 설명문은 고르지 않는다.
**③이 길어지면** — *"그중에 한 줄만 고르면요?"* B로 되돌려 넣지 않는다. **예정 재료 ①에서 이미 나왔으면 확인만 한다.**

## 6. F · 가게 사실 시트

```
이제 사실만 적는 표예요. 아는 것만, 확실한 것만 채워주세요. 모르면 비워두세요.
예정이면 정해진 것만요.

| 항목 | 내용 |
|---|---|
| 정식 상호 · 검색되는 이름 | |
| 주소 · 찾아오는 법 · 주차 (온라인이면 배송 · 배송비 · 소요일) | |
| 영업시간 · 휴무 · 라스트오더 (온라인이면 주문 마감 · 발송 요일) | |
| 대표 상품과 가격 (3개까지) | |
| 원산지 · 인증 · 자격 · 수상 (증명 가능한 것만) | |
| 시작한 연도 · 년수 | |
| 예약 · 주문 · 문의 방법 | |
| 절대 하지 않는 것 (조미료 · 냉동 · 재사용 등) — 사실인 것만 | |
```

받은 뒤 → `facts-sheet-guide.md`의 「말하면 안 되는 것」을 한 번 짚는다.

## 7. 채널 · 기둥 · 1주차 3개

```
① 그 손님(D)은 하루 중에 언제, 어디를 보고 있을까요?
   네이버 검색 · 인스타 · 카카오톡 · 스레드 · 유튜브 · 당근 · 스마트스토어 중에서요.
```
```
② (세 기둥 표를 오늘 내용으로 채워서 보여준 뒤)
   이 세 기둥으로 한 달을 갑니다. 셋 중 사장님이 제일 자신 있는 기둥은 어디예요?
```

## 되묻기 총칙

| 이런 답이 오면 | 이렇게 되묻는다 |
|---|---|
| *"좋아요"* · *"맛있어요"* · *"편해요"* | *"뭐가 안 해도 되게 되나요?"* 또는 *"~라서 좋다의 뒷부분요"* |
| 기능 · 공정 · 재료 나열 | *"그건 우리가 하는 일이고, 그래서 손님한테 뭐가 달라지나요?"* |
| *"다요"* | *"그중 제일 아쉬워할 한 분은요?"* |
| *"정성 · 진심"* | *"손님이 그걸 어떻게 알아채나요?"* |
| 사실 시트 밖의 숫자 (*"거의 30년"*) | *"정확히 몇 년이에요? 시트에는 확실한 숫자만 넣을게요"* |
| *"보통은 어떻게 해요?"* | *"보통 답은 옆 가게 답이 돼요. 사장님 가게 걸로 갈게요"* |

**되묻고도 안 나오면 힌트로 간다.** → `hint-playbook.md`
