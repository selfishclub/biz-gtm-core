# 다음 단계 — 2~4회차 연결 · 검증 숙제

## 1. 2~4회차는 첫 질문을 다시 하지 않는다

1회차 파일 여섯 개가 **인터페이스**다. 이후 회차 스킬은 프로젝트 안에서 이 파일을 읽고 시작한다.

| 회차 | 산출물 | 읽는 파일 | 첫 질문 대신 |
|---|---|---|---|
| **2회차 카드뉴스** | 발행 가능한 카드뉴스 1세트 · 재사용 카드뉴스 스킬 | 01 (B Before/After · C) · 02 · 03 · 05 | 05의 「2회차」 줄. 후킹은 Before, 결론은 After, 근거는 03 |
| **3회차 이미지** | 용도별 이미지 4종 · 브랜드 이미지 프롬프트 스킬 | 02 (보여줘도 되는 것 · 안 보여줄 것) · 03 · 05 | ① 기둥. 메뉴/제품컷 · 배너 · 프로필 · 매장 무드컷 |
| **4회차 릴스** | 완성 릴스 1편 · 릴스 기획 스킬 | 02 (말투 · 고집) · 01 (C) · 05 | ③ 기둥. 첫 1.5초는 E의 고집 한 줄 |

**검수는 전부 03 사실 시트 기준.** 시트 밖의 숫자 · 효능 · 최초/최고가 나오면 그 줄을 지운다.

### 2회차 스킬을 만들 때 지킬 것
- 프로젝트에 01~05가 있으면 **읽고 요약해서 확인만** 받는다 — *"제가 이렇게 이해했는데 맞나요?"*
- 없으면 세 가지만 묻고 시작한다 — 누구에게 · 무엇이 달라지나 · 사실 하나
- 카드뉴스 원고의 **후킹 → 공감 → 제안 → 근거 → CTA** 는 01의 Before → 대안 → After → 03 사실 → 04 채널 행동과 1:1로 맞는다

## 2. 반응이 없을 때 — 세 갈래

| 이런 신호면 | 틀린 것 | 하는 일 | 어느 파일 |
|---|---|---|---|
| 프로필까지 오는데 팔로우 안 하고 나감 | **사람** | 페르소나 교체 → 가치 다시 | 01 D → C |
| 보고 "좋네요" 하는데 안 옴 | **이유** | 가치 재정의 | 01 C |
| 와서 "아 이런 데였어요?" | **전달** | 카드뉴스 · 이미지 · 릴스를 바꿈 | 05, 2~4회차 산출물 |

**코어(B)는 가장 나중에 의심한다.** B가 틀렸다면 그건 우리가 뭘 하는 곳인지의 문제고, 한 달 뒤에 본다.

## 3. 검증 숙제 — 수업에서 돌리지 않는다

> **`virtual-customer-feedback-qa`**
> github.com/selfishclub/virtual-customer-feedback-qa
> 한국인 합성 페르소나 5명에게 직접 물어보는 스킬. 10분.

**1회차 수업 시간에는 제안하지 않는다.** 시간이 없고, 프로젝트 개설과 채널 세팅이 우선이다.
마무리 숙제로 **한 번만** 말한다.

```
집에서 하나 더 해보실 분만요.
오늘 만든 01번 파일을 가상 손님 5명한테 한번 보여볼 수 있어요.

  github.com/selfishclub/virtual-customer-feedback-qa

01번 파일을 그대로 넣으면 되고, 10분이면 끝나요.
전체를 바꾸라는 게 아니고, "어 이건 생각 못 했네" 하나 건지면 충분합니다.
```

**넘기는 프롬프트**
```
01_가치x페르소나_시트.md 로 가상 고객 피드백 받아보고 싶어.

한 문장: (B)
페르소나: (D)
가치: (C)

핵심 2 · 경계 2 · 비사용자 1로 패널 짜서 갈지 안 갈지, 왜 그런지 물어봐줘.
비사용자는 「대안」이 "그냥 안 한다 / 배달 시킨다"인 사람으로.
내가 놓친 지점이 있으면 그걸 중심으로 정리해줘.
```

## 4. 아이템을 바꾸고 싶어지면

인터뷰 중에 *"메뉴를 바꿔야 하나요"* 가 나올 수 있다. 오늘은 바꾸지 않는다.

```
오늘은 아이템을 안 바꿉니다. 뭘 앞세울지만 정해요.
한 달 콘텐츠를 돌려보고, 그때도 "전달이 아니라 이유가 틀렸다"가 계속 나오면
그때 아이템을 다시 봐요. 지금 바꾸면 뭐가 틀렸는지 알 수 없어요.
```

굳이 정하겠다고 하면 원본 스킬(`sponge-gtm-core/references/next-steps.md`)의 조건 넷만 알려준다 — 지금 만들 수 있나 · 변화를 진짜 일으키나 · 받은 사람에게 다시 말을 걸 수 있나 · 틀렸을 때 버릴 수 있나.

## 5. 원본과의 관계

| | `sponge-gtm-core` (원본) | `biz-gtm-core` (이 스킬) |
|---|---|---|
| 대상 | 아이템 없음 · 생각만 · 팔고 있음 셋 다 | **팔고 있음**만 |
| 방향 | 재료 → 변화 → 아이템은 나중 | **아이템 → 변화 역산** |
| 재료의 핵 | 환불 사유 | 단골의 말 · 안 오는 이유 |
| "왜 하필 나" | 막음 | **두 칸으로 분리해 받음** (우리 쪽 / 사장님) |
| E · F 블록 | 없음 | 사장님 보이스 · 사실 시트 |
| 산출 | 문서 한 장 | **지침 1 + 지식 파일 5** |
| 후속 | 1차 전환 → 캐러셀 | 카드뉴스 → 이미지 → 릴스 |

아이템이 없는 사람이 오면 원본으로 보낸다. 원본의 유형 3이 소상공인이면 이 스킬로 보낸다.
