# 완성 예시

사용자가 예시를 요청하거나 감이 안 잡힐 때 보여준다. **자기 업종과 비슷한 것 하나만.** 전체를 다 보여주면 오히려 그 예시에 갇힌다.

---

## 반찬가게 · 6년차 · 망원동

### 0. 소개
반찬 15종 매일 조리 · 망원동 골목 매장 + 카카오 주문 · 6년 · 인스타 개인 계정에 가끔 사진

### A · 재료

| | |
|---|---|
| 단골이 소개할 때 하는 말 | **"거기는 반찬이 안 남아"** · "조미료 안 쓰는 집" |
| 처음 온 사람이 묻는 것 | "이거 며칠 가요?" · "혼자 살면 몇 개 사요?" |
| 한 번 오고 안 오는 이유 | (짐작) 마트보다 비싸다고 느낌 · 주차 안 됨 |
| 리뷰에 반복되는 말 | "간이 세지 않아서 좋아요" · "양이 적어요" |
| 지금 채널 | 인스타 개인 · 네이버 플레이스 |

### B · 변화

| | |
|---|---|
| 가장 만족한 손님이 얻어 간 것 | 퇴근하고 밥만 하면 되는 저녁 |
| **Before** | 퇴근길에 뭐 먹을지 매일 고민. 배달 시키고 죄책감 |
| **After** | **밥만 하면 저녁이 됨.** 배달 앱을 덜 켬 |
| 대안 | 배달. 아니면 대충 라면 |
| 대체 불가 — 가게 기준 | 매일 아침 새로 함. 조미료 안 씀. 1인분 소포장 |
| 대체 불가 — 사장님 기준 | 한식조리기능사 · 급식 조리 12년 후 개업 (확인 가능) |

> ## "우리 가게는 반찬을 파는 게 아니라,
> ## 퇴근하고 밥만 하면 되는 저녁을 판다."

### D · 손님 한 분
| | |
|---|---|
| 한 명으로 좁히면 | 망원동 원룸 사는 30대 직장인. 혼자 살고 퇴근이 늦다 |
| 오기 직전에 | 배달 앱을 켰다가 닫았다. "또 시켜?" |
| 왜 원하나 | 집밥 먹고 싶은데 만들 기운은 없다 |
| 하루 중 어디를 보나 | 퇴근길 인스타 · 카카오톡 |

### C · 그 손님의 말
> **"거기 반찬 사놓으면 배달 앱을 안 켜게 되더라"** *(실제로 들은 말)*

**테스트** — 손님 입에서 나올 말인가 ⭕ · 손님을 4인 가족 주부로 바꾸면 바뀌는가 ⭕ (*"애들이 골고루 먹어요"* 가 될 것) · 옆 반찬가게도 할 수 있는 말인가 — "배달 앱을 안 켜게" 는 이 손님과 이 가게의 조합에서만 나온다 ⭕

### E · 사장님
| | |
|---|---|
| 말투 표본 (대화에서) | *"그냥 매일 새로 해요"* · *"저는 그거 안 해요"* · *"먹어보면 알아요"* |
| 안 쓰는 말 | "엄마 손맛" · "집밥 감성" · 이모지 |
| 안 보여줄 것 | 얼굴 · 주방 전체 |
| 보여줘도 되는 것 | 손 · 재료 · 담는 장면 · 매장 진열 |
| 왜 시작했나 | 급식에서 못 하던 걸 하고 싶어서 |
| 고집 | **조미료를 안 쓴다. 대신 매일 한다** |

### F · 사실 시트 (일부)
| | |
|---|---|
| 영업시간 | 화~토 11:00–20:00 · 월 휴무 |
| 주차 | 안 돼요 (근처 공영 유료) |
| 대표 상품 | 무말랭이 4,000 · 소불고기 9,000 · 3찬 세트 12,000 |
| 인증 | 한식조리기능사 (증명 가능) |
| 시작 | 2020년 |
| 절대 하지 않는 것 | 조미료(MSG) 사용 · 전날 반찬 판매 |
| **쓰면 안 되는 것** | "건강한" · "다이어트" · "엄마 손맛"(사장님이 싫어함) · "망원동 1등" |

### 채널 · 방향
- 인스타 필수 · **카카오채널 1순위** (재구매가 매출) · 스레드 권장 (말투가 산다)
- 자신 있는 기둥: ① 상품 → 1주차
- 2회차 카드뉴스: *"배달 앱을 켰다가 닫은 밤"* 에서 시작 → *"밥만 하면 되는 저녁"* 으로

> **이 케이스의 발견**
> 사장님은 처음에 *"조미료 안 쓰는 반찬을 판다"* 고 했다. 그건 **가게 기준의 대체 불가**고, 변화가 아니다.
> 가장 만족한 손님 이야기를 꺼내자 *"밥만 하면 된다"* 가 나왔다. 조미료는 **왜 우리인가**의 근거로 내려갔고, 변화는 **저녁이 해결된다**로 올라갔다.
> **아이템(반찬)은 하나도 안 바꿨다. 앞세우는 것만 바뀌었다.**

## 짧은 예시 — 다른 업종의 한 문장과 가치

| 업종 | 한 문장 | 손님(D) | 그 손님의 말(C) |
|---|---|---|---|
| 네일샵 | 네일을 파는 게 아니라, **2주에 한 번 나를 챙기는 시간**을 판다 | 육아 중 첫 외출하는 30대 | *"거기 가면 한 시간은 아무도 안 불러요"* |
| 동네 카페 | 커피를 파는 게 아니라, **노트북 펴도 눈치 안 보이는 두 시간**을 판다 | 재택하다 집이 답답한 프리랜서 | *"콘센트 있고 아무 말 안 해요"* |
| 필라테스 | 수업을 파는 게 아니라, **허리 안 아픈 출근길**을 판다 | 앉아서 일하는 40대 사무직 | *"3주 됐는데 아침에 허리를 안 잡아요"* |
| 꽃집 | 꽃을 파는 게 아니라, **뭘 사야 할지 몰라도 되는 선물**을 판다 | 기념일 앞둔 30대 남성 | *"예산만 말하면 알아서 해줘요"* |
| 영어 학원 | 수업을 파는 게 아니라, **학원 갔다 와서 숙제 안 시켜도 되는 저녁**을 판다 | 초등 저학년 워킹맘 | *"숙제를 거기서 다 하고 와요"* |

**공통** — 뒷칸이 전부 **손님의 하루에서 달라지는 것**이다. 상품 특징이 아니다.

| 칸 | ❌ 이렇게 나오면 | 왜 | 되묻기 |
|---|---|---|---|
| 한 문장 | *"우리는 정직한 반찬을 판다"* | 변화가 없다. 주장 | *"정직하면 손님 하루에서 뭐가 달라져요?"* |
| 한 문장 | *"반찬을 파는 게 아니라 건강과 시간과 행복을 판다"* | 세 칸 | *"하나만 남기면요?"* |
| 대체 불가 (사장님) | *"제가 진심이라서요"* | 확인 불가 | *"손님이 그걸 어떻게 알아채요?"* |
| 가치 | *"매일 새로 만든 신선한 반찬"* | 사장님 말 | *"손님이 친구한테 카톡으로 보낼 말로요"* |
| 가치 | *"밥만 하면 저녁이 돼요"* | 변화 복붙 | *"그건 우리가 정한 변화고, 손님은 뭐라고 할까요?"* |

| 사실 시트 | *"면역력에 좋은 도라지"* | 효능 | *"효능은 못 써요. 도라지가 국내산이라는 건 쓸 수 있어요"* |

## 설문에서 온 업종 — 짧은 예시 세 개 (v0.2 추가)

| 상황 | 한 문장 | 손님(D) | 그 손님의 말(C) | 비고 |
|---|---|---|---|---|
| **온라인몰 · 스마트스토어** (매장 없음) | 운동복을 파는 게 아니라, **사이즈 고민 없이 결제 버튼을 누르는 10초**를 판다 | 온라인에서 옷 사고 두 번 반품한 40대 | *"여긴 사이즈표가 진짜 맞아요"* (재구매 후기) | 단골의 말 → 재구매 후기, 처음 질문 → Q&A, 안 사는 이유 → 반품 사유 |
| **주문형 떡공방** (SNS · 전화 주문, 픽업 · 퀵) | 떡을 파는 게 아니라, **답례 고민이 끝나는 한 통의 카톡**을 판다 | 돌잔치 · 개업 답례 준비하는 30대 | *"카톡으로 사진 하나 보내니까 알아서 해주셨어요"* | 대안이 "인터넷 대량 주문 또는 안 함". 카카오채널이 주문 창구 |
| **창업 예정 · 팔 것은 정함** (꽃 · 공방) | 꽃 수업을 파는 게 아니라, **평일 저녁 두 시간 아무 생각 안 하는 시간**을 판다 | 퇴근 후 뭔가 배우고 싶은데 부담은 싫은 30대 | *(짐작)* *"손만 움직이니까 머리가 비어요"* — 첫 손님 3명에게 확인 | A′ 예정 재료: 본인이 손님이었을 때 "수업이 너무 진지해서 부담"이 Before가 됨 |

**온라인몰의 핵심** — "지나가다가"가 없다. Before는 **화면 앞에서 망설이는 장면**이고, 대체 불가의 가게 기준은 배송 · 사이즈표 · 상세 사진 같은 **화면에서 확인되는 것**이다.
**주문형의 핵심** — 카카오채널이 SNS가 아니라 **주문 창구**다. 웰컴 메시지가 곧 주문 안내다.
**창업 예정의 핵심** — C는 짐작이다. 지어내지 말고 「짐작」이라고 쓰고, `01`의 「비어 있는 것」에 *"첫 손님 3명에게 듣기"* 를 넣는다.
