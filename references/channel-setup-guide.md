# 채널 세팅 가이드 — 문안 · 순서 · 화면이 다를 때

STEP 7-③과 STEP 8에서 읽는다. **스킬은 문안과 순서를 준다. 클릭은 사용자가 한다.**

**기준일: 2026년 9월.** 앱 화면은 자주 바뀐다. 아래 순서는 방향이고, 버튼 이름은 다를 수 있다.

---

## 화면이 다를 때 — 이 프로토콜을 먼저 말한다

세팅 안내를 시작할 때 **반드시** 이렇게 말한다.

```
지금부터 순서를 알려드릴게요. 앱 화면은 자주 바뀌어서 버튼 이름이 다를 수 있어요.
설명과 다른 화면이 나오면 그 화면을 캡처해서 올려주세요. 보고 다음 버튼을 알려드릴게요.
```

| 상황 | 대응 |
|---|---|
| *"그런 메뉴가 없어요"* | *"지금 보이는 화면 캡처해주시겠어요?"* → 캡처 기준으로 다시 안내 |
| 캡처가 왔는데 낯선 화면 | 화면의 글자를 읽고 **가장 비슷한 이름**을 짚는다. 확신 없으면 *"이 중에 '계정' 이나 '도구' 비슷한 게 있나요?"* |
| 캡처를 못 올림 | *"화면에 보이는 메뉴 이름을 위에서부터 읽어주세요"* |
| 앱 업데이트 요구 | 업데이트 후 진행. 기다리는 동안 문안을 고친다 |
| **비밀번호 · 인증번호 · 결제 화면** | **절대 대신 하지 않는다.** *"이건 사장님이 직접 입력하시고, 다음 화면 오면 알려주세요"* |

**안내를 고집하지 않는다.** 화면이 진실이다.

## A. 인스타그램 — 비즈니스(프로페셔널) 계정

### 세팅 순서 (기준일 2026-09)

```
① 인스타그램 앱 → 오른쪽 아래 프로필 → 오른쪽 위 ☰ → 「설정 및 활동」
② 「계정 종류 및 도구」 → 「프로페셔널 계정으로 전환」
③ 카테고리 선택 — 우리 업종에 가장 가까운 것 (카페 · 음식점 · 미용실 · 학원 …)
④ 「비즈니스」 선택 (크리에이터가 아니라)
⑤ 연락처 표시 여부 — 전화 · 이메일 · 주소 중 F 시트에 있는 것만
⑥ 페이스북 페이지 연결 — 오늘은 「건너뛰기」 해도 된다
⑦ 프로필 편집 → 아래 문안 입력
```

**주의** — 프로페셔널 전환하면 계정이 **공개**로 바뀐다. 비공개로 쓰던 분은 미리 말해준다.
**이미 프로페셔널이면** ①~⑥을 건너뛰고 ⑦만 한다.

### 프로필 문안 — A~F에서 나온 말로만

| 칸 | 규칙 | 재료 |
|---|---|---|
| **이름** (검색에 걸리는 칸) | `상호 · 지역 · 업종` 순. 예: `한끼반찬 · 망원동 반찬가게` | F 상호 · 주소 |
| **사용자 이름** (@아이디) | 이미 있으면 그대로. 새로 만들면 상호 영문 + 지역 | F |
| **소개** (150자) | **1줄: B 뒷칸을 사장님 말로 / 2줄: C 가치(손님 말) / 3줄: F 사실 하나(영업시간 또는 위치) / 4줄: 행동 하나(예약 · 채널 추가 · 링크)** | B · C · F |
| **링크** | 카카오채널 또는 네이버 예약 또는 플레이스 **하나**. 여러 개면 링크 모음 서비스 | F 문의 방법 |
| **카테고리** | ③에서 고른 것 | |
| **연락처** | F 시트에 있는 것만 | F |

**소개 초안은 두 개 낸다.** 하나는 사장님 말투(E-①) 그대로, 하나는 조금 정돈된 것. 사용자가 고르고 고친다.

```
예 (반찬가게)
저녁 걱정 없는 퇴근길을 만듭니다
"여기 반찬은 안 남아요" — 단골 말
망원동 · 화~토 11:00–20:00 · 월요일 휴무
▼ 카카오채널 추가하면 이번 주 반찬을 먼저 알려드려요
```

### 하이라이트 (있으면)

세 기둥에 맞춰 **세 개만** — `메뉴` · `손님` · `사장님`. 오늘은 이름만 정하고 비워둔다.

## B. 카카오톡 채널

### 세팅 순서 (기준일 2026-09)

```
① PC 브라우저에서 「카카오 비즈니스 파트너센터」 접속 (business.kakao.com)
   ※ 전 「카카오톡채널 관리자센터」에서 이름이 바뀌었다
② 카카오 계정으로 로그인 → 처음이면 약관 동의 → 「카카오 비즈니스 통합 회원」 전환
③ 「새 채널 만들기」
④ 채널 이름 · 검색용 아이디 · 카테고리 입력 (아래 문안)
⑤ 프로필 → 프로필 설정 → 채널 정보 → 「고객센터 연락처」 등록  ← 빠뜨리면 나중에 메시지 못 보냄
⑥ 대시보드에서 「채널 공개하기」 ✔ · 「검색 허용하기」 ✔
⑦ 메시지 → 「웰컴 메시지」 → 아래 문안으로 교체
⑧ (선택) 채널 → 「비즈니스 심사」 — 사업자등록증 제출. 3~5일. V 뱃지 · 알림톡 가능
```

**⑧은 오늘 안 해도 된다.** 서류가 있으면 신청만 걸어둔다.
**사업자등록증 · 신분증 업로드는 사장님이 직접 한다.**

### 문안

| 칸 | 규칙 | 재료 |
|---|---|---|
| **채널 이름** | 상호 그대로. 20자 이내 | F 상호 |
| **검색용 아이디** | 상호 영문 또는 한글 발음. 나중에 못 바꾸니 신중히 | F |
| **소개** | 인스타 소개 1~2줄 재사용 | B · C |
| **웰컴 메시지** | **사장님 말투로 2~3줄.** 무엇을 보내줄지 하나만 약속. 팔지 않는다 | E-① · content-direction |

```
예 (반찬가게)
채널 추가 고맙습니다 🙂
매주 화요일에 이번 주 반찬 사진만 하나 보내드릴게요.
필요한 거 있으시면 여기로 편하게 말씀 주세요.
```

### 매장에 붙일 것
채널 추가 **QR 이미지**를 파트너센터에서 내려받아 계산대에 붙인다. 3회차 배너 이미지의 재료가 된다.

## C. 스레드 (Threads)

### 세팅 순서 (기준일 2026-09)

```
① Threads 앱 설치 → 「Instagram으로 로그인」 — 위에서 세팅한 인스타 계정으로
② 프로필 가져오기 — 사진 · 소개는 가져오되, 스레드에서 따로 고칠 수 있다
③ 팔로우 계정 가져오기 — 선택. 안 해도 된다
④ 프로필 편집 → 소개를 아래 문안으로 (인스타보다 짧고 말투가 살아 있게)
⑤ 첫 글 하나 올린다 — 아래 문안
⑥ 인스타 프로필의 「Threads 배지 표시」는 켜둔다 (프로필 편집 맨 아래)
```

### 문안

| 칸 | 규칙 | 재료 |
|---|---|---|
| **소개** | 한 줄. **E-① 말투 그대로.** 예: `망원동에서 반찬 만듭니다. 조미료는 안 써요.` | E · F |
| **첫 글** | E-③의 「고집」 한 줄 + 오늘 있었던 일 한 줄. 사진 없어도 된다 | E-③ |

```
예
저는 반찬에 조미료를 안 씁니다. 대신 매일 새로 합니다.
오늘은 오전에 무말랭이 무쳤어요. 저녁엔 다 나갈 것 같아요.
```

## D. ChatGPT 프로젝트 개설

STEP 8에서 파일 여섯 개를 만든 뒤 안내한다. **수업 도구는 ChatGPT다.** 클로드를 쓰는 분은 아래 「클로드인 경우」로.

```
① ChatGPT 왼쪽 메뉴 → 「프로젝트」 → 「새 프로젝트」
② 이름: 「(상호) 마케팅」
③ 프로젝트 안 「지침」(Instructions) 열기 → 00_프로젝트_지침.md 내용을 전부 붙여넣기 → 저장
④ 「파일」(Files) → 01 ~ 05 파일 다섯 개 업로드
⑤ 프로젝트 안에서 새 대화 → 테스트 질문:
   "우리 가게 소개를 손님 말로 세 줄만 써줘"
```

| 테스트 결과 | 뜻 | 조치 |
|---|---|---|
| 사실 시트에 있는 것만 나옴 · 사장님 말투 | 정상 | 끝 |
| 시트에 없는 숫자 · "30년 전통" 등 | 지침이 안 붙었거나 03 파일이 안 올라감 | ③ ④ 확인 |
| 존댓말 광고체 · 이모지 남발 | 02 파일이 안 읽힘 | 02 업로드 확인, 지침에 「02 참조」 줄 확인 |
| 페르소나와 다른 사람에게 말함 | 01이 안 읽힘 | 01 업로드 확인 |

**무료 계정** — 프로젝트 기능은 쓸 수 있지만 파일 개수 · 용량 한도가 요금제별로 다를 수 있다. 다섯 개가 다 안 올라가면 **01 · 02 · 03 세 개를 먼저** 올리고, 04 · 05는 대화에 첨부한다.
**프로젝트 메뉴가 안 보이면** — 앱 업데이트 또는 웹(chatgpt.com)으로. 그래도 없으면 새 대화에 00을 붙이고 파일을 첨부하는 방식으로 2회차까지 갈 수 있다.
**지침 글자 수 한도**에 걸리면 00의 「이 프로젝트가 하지 않는 것」 절을 빼고 붙인다. 사실 규칙은 빼지 않는다.

### 클로드인 경우
```
클로드 앱 → 「프로젝트」 → 「새 프로젝트」 → 「지침 설정」에 00 붙이기 → 「지식 추가」에 01~05 업로드 → 같은 테스트 질문
```

## E. 네이버 플레이스 — 소개글 갱신 (10분)

**새로 만들지 않는다.** 대부분 이미 있고, 손님이 실제로 찾아오는 길이다. 오늘 만든 문안으로 **소개글만 바꾼다.**

```
① 네이버 스마트플레이스 앱 또는 smartplace.naver.com → 로그인
② 「업체 정보」 → 「소개글」 (또는 「업체 설명」)
③ 아래 문안으로 교체 → 저장
④ (있으면) 「대표 키워드」에 지역 + 업종 + 대표 상품
```

| 칸 | 규칙 | 재료 |
|---|---|---|
| **소개글 첫 줄** | B 뒷칸을 사장님 말로 | B · E |
| **둘째 줄** | C 가치 (손님 말) 또는 A-① 단골의 말 | C · A |
| **셋째 줄** | F 사실 하나 — 절대 하지 않는 것 또는 대표 상품 | F |
| **대표 키워드** | 지역 · 업종 · 대표 상품 · (예정이면 비움) | F |

**온라인 판매자**는 플레이스 대신 **스마트스토어 상세페이지 첫 화면**의 소개 문장을 같은 규칙으로 바꾼다.
**화면이 다르면** 캡처 프로토콜 그대로.

## 이 파일을 고칠 때

- 앱 UI가 바뀌면 **기준일을 갱신**하고 순서만 고친다. 문안 규칙은 건드리지 않는다
- 수업에서 캡처로 확인된 새 화면은 여기 반영한다
