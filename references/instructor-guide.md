# 강사용 진행 가이드 — 1회차 하루

**대상** — 이미 파는 것이 있는 소상공인 20~30명. 각자 노트북에서 자기 클로드 계정으로 스킬을 돌린다.
**목표** — 퇴장할 때 손에 들고 나가는 것 셋: **가치×페르소나 시트 · 클로드 프로젝트 · 1개월 콘텐츠 방향.**

이 파일은 스킬이 사용자에게 보여주는 파일이 아니다. **강사가 읽는다.**

---

## 하루 타임라인 (09:30–17:30)

| 시간 | 블록 | 내용 | 체크포인트 |
|---|---|---|---|
| 09:30–10:00 | 오프닝 | 드릴과 구멍 · 3층 구조 · 오늘 나가는 것 셋 · 클로드 앱 로그인 확인 · **"모르겠다고 해도 됩니다"** 선언 | 전원 로그인 · 스킬 발동 확인 |
| 10:00–10:20 | STEP 0~1 | 가게 소개 · A 재료 4문항 | *"단골이 뭐라고 하는지 적으신 분 손"* |
| 10:20–11:20 | STEP 2~4 | B 변화 → D 손님 → C 가치. **여기가 핵심 한 시간** | 10:50 *"한 문장 나온 분"* · 11:15 *"손님 말 나온 분"* |
| 11:20–12:00 | STEP 5~6 | E 사장님 · F 사실 시트 | *"사실 시트에서 못 채운 칸 하나씩 말해보세요"* |
| 12:00–13:00 | 점심 | | |
| 13:00–13:40 | STEP 7~8 | 채널 우선순위 · 세 기둥 · 문안 · **파일 여섯 개 생성** | *"00번 파일 열어본 분"* |
| 13:40–14:30 | 프로젝트 개설 | 새 프로젝트 → 지침 붙이기 → 파일 5개 업로드 → **테스트 질문** | 테스트 답에 시트 밖 숫자가 나오면 손 |
| 14:30–16:20 | 채널 세팅 실습 | 인스타 비즈니스 전환 40분 · 카카오채널 40분 · 스레드 20분 (+10분 버퍼) | 각 채널 끝날 때 *"프로필 소개 넣으신 분"* |
| 16:20–17:10 | 공유 | 한 문장 낭독 (원하는 분 8~10명) · 옆 사람에게 *"그래서 뭐가 달라져요?"* 묻기 | |
| 17:10–17:30 | 마무리 | 반응 없을 때 세 갈래 · 2회차 예고 · 숙제 | 파일 여섯 개 보관 확인 |

**밀리면 여기서 뺀다** — E-③(왜 시작했나) → A-④(리뷰) → 스레드 세팅. **B·D·C와 프로젝트 개설은 빼지 않는다.**

## 오프닝에서 꼭 말할 것

1. **"여러분은 아이템이 있으세요. 오늘은 그걸 바꾸는 날이 아니에요. 그게 누구의 무엇을 바꾸는지 적는 날이에요."**
2. **"모르겠다고 치셔도 됩니다. 빈칸은 다음 주에 손님한테 물어볼 목록이 돼요."**
3. **"AI가 써준 문장을 그대로 확정하지 마세요. 꼭 사장님 말로 한 번 고치세요."**
4. **"계정 비밀번호, 인증번호는 AI한테 절대 알려주지 마세요. 그건 직접 치세요."**
5. 3층 구조 그림 — 내가 파는 것 / 사는 사람 / 나라는 사람 → 이게 그대로 한 달 콘텐츠 세 기둥이 된다

## 자주 막히는 지점과 개입 문구

| 지점 | 증상 | 강사 개입 |
|---|---|---|
| A-③ 안 오는 이유 | 전원 "모르겠어요" | *"모르는 게 정상이에요. 짐작으로 하나만 치고 넘어가세요. 그게 오늘 숙제가 됩니다"* |
| B-② Before/After | 메뉴 설명이 나옴 | 옆 사람 페어: *"옆 분한테 '그래서 손님 하루에서 뭐가 달라져요?' 한 번 물어보세요"* |
| B-⑤ 한 문장 | AI 초안을 그대로 확정 | *"셋 중 하나 고르셨으면 사장님 말로 한 단어라도 바꾸세요. 안 바꾸면 남의 문장이에요"* |
| D 페르소나 | "다요" | *"지난달 계산하면서 제일 기분 좋았던 손님 한 분요"* |
| C 가치 | 사장님 말이 나옴 | *"그 손님이 친구한테 카톡으로 뭐라고 보낼까요"* |
| E-① 말투 | "저는 말투가 없어요" | *"지금 AI한테 친 문장 세 개가 화면에 있어요. 그게 말투예요"* |
| F 사실 시트 | 부풀림 ("거의 30년") | *"정확한 연도로요. 시트는 증명할 수 있는 것만"* |
| 파일 생성 | 파일이 안 내려받아짐 | 코드블록 복사 → 메모장에 붙이고 `.md`로 저장. 파일명 그대로 |
| 프로젝트 | 「프로젝트」 메뉴가 없음 | 요금제 확인. 없으면 **파일을 대화에 첨부**하는 방식으로 2회차 진행 가능하다고 안내 |
| 인스타 전환 | 화면이 안내와 다름 | *"AI한테 캡처 올리고 '이 화면에서 다음 어디 눌러요?' 물어보세요"* |
| 카카오채널 | 사업자등록증 없음 | 일반 채널로 개설. 비즈니스 심사는 서류 준비되면 |
| 타이핑 느림 | 진도 차이 | *"단어로만 치셔도 돼요"* · 빠른 분은 F 사실 시트를 먼저 채우게 |

## 체크포인트 운영

- **손들기**로 진도를 본다. 절반 넘으면 다음으로, 절반 안 되면 5분 더
- 진도 빠른 분에게 **"옆 분 한 문장 들어주기"** 역할을 준다. 기다리는 시간이 페어 활동이 된다
- **한 문장 낭독**은 강제하지 않는다. 8~10명이면 충분하고, 낭독할 때마다 *"그래서 뭐가 달라지나요?"* 를 한 번 되묻는다

## 프로젝트 테스트 질문 — 전원 같은 걸로

```
우리 가게 소개를 손님 말로 세 줄만 써줘
```

| 결과 | 진단 |
|---|---|
| 시트 안의 사실 · 사장님 말투 · 손님 말 인용 | 정상 |
| "30년 전통", "최고의" 등 | 00 지침이 안 붙었거나 03이 안 올라감 |
| 광고체 · 이모지 | 02가 안 읽힘 |
| 페르소나와 다른 사람에게 말함 | 01이 안 올라감 |

## 마무리에 꼭 말할 것

1. **"오늘 세운 건 오늘 기준이에요. 바뀝니다."**
2. 반응 없을 때 세 갈래 — 사람 / 이유 / 전달. **"SNS는 우리랑 안 맞네"로 뭉치지 않기**
3. **2회차는 이 프로젝트 안에서 시작한다.** 첫 질문 다시 안 한다. 05번 파일의 2회차 줄이 첫 카드뉴스 주제
4. **숙제 (선택)**
   - A-③ 빈칸: 이번 주 계산할 때 세 분에게 *"처음 오셨어요? 어떻게 알고 오셨어요?"*
   - 가상 고객 검증 (`virtual-customer-feedback-qa`) — 원하는 분만. 10분
   - 채널 세팅 못 끝낸 것 마무리
5. **파일 여섯 개를 어디 저장했는지 확인하고 퇴장**
