# ChatGPT 프로젝트 하나로 돌리는 방법

**커스텀 GPT를 쓰지 않는다.** 참가자마다 ChatGPT 프로젝트 하나를 만들고, 그 안에서 인터뷰를 하고, 그 안에 산출 파일이 쌓인다. 2~4회차도 같은 프로젝트다.

## 참가자가 오프닝에서 하는 것 (10분)

```
① ChatGPT 왼쪽 「프로젝트」 → 「새 프로젝트」 → 이름: 「(상호) 마케팅」
② 「지침」 열기 → 프로젝트_지침.md 내용 전부 붙여넣기 → 저장
③ 「파일」 → 인터뷰_참조_묶음.md 한 개 업로드
④ 새 대화 → "비즈니스 GTM 코어 시작할게요" (창업 준비 중이면 "창업 준비 중인데 시작할게요")
```

지침과 참조 묶음은 강사가 **단톡방에 파일로 올린다.** 참가자는 복사와 업로드만 한다.

## 두 모드 — 지침 하나가 알아서 바뀐다

| 프로젝트 파일 상태 | 모드 | 하는 일 |
|---|---|---|
| 참조 묶음만 있음 | **인터뷰** | 20개 질문 → 01~05 다섯 파일 생성 |
| 01~05가 올라감 | **마케팅** | 카드뉴스 · 이미지 · 릴스 · 캡션을 파일 기준으로 |

인터뷰가 끝나면 GPT가 다섯 파일을 준다. 참가자가 **같은 프로젝트 「파일」에 올리면** 끝이다. 지침을 바꿔 붙이지 않는다.

## 웹 조회

프로젝트 안에서 ChatGPT 검색이 켜져 있으면 지침이 세 지점(사전 확인 · 규정 · 검색어/시즌)에서 알아서 조회한다. 검색이 안 되는 계정이면 GPT가 "조회를 못 했으니 강사님 표를 보세요"라고 말하고 넘어간다. → `../references/research.md`

## 참조 묶음 만들기 (강사, 전날)

`references/` 아래 파일을 한 파일로 합친다. 무료 계정의 파일 개수 한도를 피하기 위해서다.

```bash
cd biz-gtm-core && bash chatgpt/build-bundle.sh
```

`chatgpt/인터뷰_참조_묶음.md`가 만들어진다. `references/`를 고치면 다시 돌리고 단톡방에 다시 올린다.

## 전날 확인

- [ ] **무료 ChatGPT 계정**으로 프로젝트 만들기 · 지침 붙이기 · 참조 묶음 업로드 · 인터뷰 시작이 되는지
- [ ] 같은 계정에서 **웹 검색**이 되는지 (안 되면 강사 표로 대체한다고 오프닝에서 말한다)
- [ ] 인터뷰 뒤 **01~05 다섯 개 추가 업로드**가 한도에 걸리지 않는지. 걸리면 참조 묶음을 지우고 올린다
- [ ] 프로젝트 안 **이미지 생성**이 되는지 (블록 5)
- [ ] 지침 글자 수 8,000자 이내 (`프로젝트_지침.md`는 약 4,100자)

## 클로드로 리허설할 때

`SKILL.md`가 원본 규격이다. `~/.claude/skills/biz-gtm-core`로 링크돼 있으면 "비즈니스 GTM 코어 잡아줘"로 발동한다.

## 두 버전을 함께 고치는 규칙

- 질문 문장 · 양식 · 규칙은 `references/`에만 있다. 지침은 **순서와 원칙만**
- `references/`를 고치면 `build-bundle.sh`를 다시 돌린다. 지침은 안 바꿔도 된다
- `SKILL.md`의 STEP 구조를 바꾸면 `프로젝트_지침.md`의 「인터뷰 모드 순서」도 같이 고친다
